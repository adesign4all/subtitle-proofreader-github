# 科普问答访谈字幕校对规则库

> 适用场景：剪映AI语音识别生成的字幕，内容为科普类问答访谈（一问一答形式）。本规则库定义**三种工作方式**与**纯文本模式**，流程边界清晰、不得混淆：
> - **工作方式一：视频直出字幕（仅视频输入）**——读取视频语音 → 根据视频语音停顿与意群合理断句（**表述的完整一句话就是一条字幕（不凑字、不强拆）**，**一条字幕只有一行字、这一行最多不超过17个字（17字是上限不是目标）**，只有一句话超过17字时才拆成多条字幕（**"XX的XX"偏正短语整体放在一条字幕中、不拆条**）直接生成字幕SRT → 按本规则库二次校对（**允许重新断句拆条：合并过碎拆句、重拆不当长句，单条≤17字**）→ 中间产物保存在**AI生成产物的默认存储路径**、**在原视频文件夹**下生成校对完成的 SRT（见第十章）。
> - **工作方式二：视频+字幕比对（视频文件 + 对应字幕SRT）**——第一步读取视频语音与字幕逐条比对、**初步校对**（文字准确度问题直接修正；**漏句（语音中有、字幕没有的遗漏内容）按语音直接补加字幕条目，多句（字幕有、语音没有的多余内容）直接删除条目**——补加/删除后条目序号连续重排、均写入修改说明表，时间偏移仍只标注不擅改，见 9.3）；第二步按本规则库**二次校对**（**允许重新断句拆条：合并过碎拆句、重拆不当长句，单条≤17字**；未涉及条目序号/时间码/空行保持原样，条目文本保持单行不换行）→ 中间产物保存在**AI生成产物的默认存储路径**、**在原字幕SRT文件夹**下生成校对完成的 SRT（见第九章）。
> - **工作方式三：仅字幕SRT直接二次校对（仅字幕SRT输入，无视频）**——跳过音频比对，**直接对提供的字幕执行二次校对**（**允许重新断句拆条：合并过碎拆句、重拆不当长句，单条≤17字**；未涉及条目序号/时间码/空行保持原样，条目文本保持单行不换行）→ **在原字幕SRT文件夹**下生成校对完成的 SRT（见第十一章）。
> - **纯文本模式**：仅提供纯文本字幕（无时间码）时，直接执行二次校对，输出全文文本。
> 三种工作方式的**二次校对共用同一套规则、按固定顺序执行**（见下方「二次校对执行顺序」），确保校对口径一致、准确度稳定。
> 校对目标：让字幕从"AI听写稿"变成"可读的规范成文"，**删除所有口语用词与除书名号外的所有标点符号**，**为提及的著作文章等作品名添加书名号《》**，**用空格隔写并列词与语音停顿处**（**校对过程中不换行，字幕条目保持单行，空格是唯一的分隔手段**），同时保留科普内容的准确性。**生成模式**下断句拆条发生在生成阶段（根据视频语音合理断句，**按视频语音的语序内容合理断句——表述的完整一句话就是一条字幕（不凑字、不强拆）**，**一条字幕一行、一行最多≤17字（17字是上限不是目标）**，只有一句话超过17字时才拆成多条字幕；**"XX的XX"偏正短语整体不拆条，放在同一条字幕中**）；**二次校对同样允许重新断句拆条——合并过碎的拆句（同一句完整语义被拆成的多个短条目、尤其≤5字孤立语块）为一条（合并后≤17字、时间码合并为该句语音起止），长句断句有问题（断点落在语义中途/意群割裂/语序错乱）也可重新拆分合并（拆点取语音停顿或意群边界、偏正短语不拆）；任何一条字幕只有一行文本、不超过17字（17字是上限不是目标）**。**说话人切换强制拆条（多人对话场景，见 10.2 第10条）**：**两人及以上对话时，不同说话人的话必须拆成独立字幕条目——即使接话紧密（时间戳间隙 <0.3s）、即使每段字数很少（"嗯""好""对""可以"等一两字也是独立一条），绝不允许把不同人的话凑在一条字幕里；合并过碎拆句仅限同一说话人自己的话，不得跨说话人合并。**
> 输出位置：**工作方式一中间产物（生成稿等）保存在AI生成产物的默认存储路径、校对完成SRT在原视频文件相同文件夹下输出**（`原视频名_校对完成.srt`；生成稿 `原视频名_字幕.srt` 保存在AI默认存储路径）；**工作方式二中间产物（初步校对稿等）保存在AI生成产物的默认存储路径、校对完成SRT与原字幕 SRT 相同文件夹下输出**（`原文件名_校对完成.srt`）；**工作方式三与原字幕 SRT 相同文件夹下输出**（`原文件名_校对完成.srt`，跳过音频比对、直接二次校对，无中间产物）；三者均生成 UTF-8 编码、可直接重新导入剪映的 SRT。

---

**二次校对执行顺序（所有模式共用，严格按序执行；每处修改须能指出规则依据，找不到依据的不改，避免主观过度修改）**：

| 顺序 | 检查项 | 判断标准（对应章节） | 完成标志 |
|------|--------|---------------------|---------|
| ① | 通读理解与查证准备（含**繁简统一**） | 通读全文，确认主题、对话双方身份、科普语境；**多人对话场景（问答访谈/聊天/接话）标注每句话的说话人归属（[Q]/[A]），识别说话人切换点（见 10.2 第10条）**；**先确定节目所属系列，按 1.7.6 索引加载对应系列专有名词词表（见 1.7），词表内已确认词条直接采用、不再重复查证**；**检查文本繁简体——输入/转写为繁体时先转简体（1.6），默认输出简体**；标注疑似专有名词/专业用语/指代名词，先查证（1.4） | 查证完成，繁简已统一，说话人切换点已识别，待改项已标记 |
| ② | 错字校对（含口音/方言分辨） | 同音/近音字、识别错误、术语误写；**先辨别说话人的方言归属（哪一地区方言，识别音变特征与方言词），有则按 1.5 执行——按该方言音变规律强化识别：按音位批量排查系统性错字、方言词保留不强行翻译、整词还原、存疑标注**；专有名词/术语查证后再改（第一章）；**工作方式一/二（有视频）音频无法确定用词时，定位画面查看有无相关文字显示核对（1.5.3 步骤5）** | 无错字遗留；口音类修改已标注【口音】；画面核对确认的修改已标注【画面核对】 |
| ③ | 口语词清理 | 语气词（含应答"嗯/啊/哦"）、"呢"字尾、"这个/那个"无实指填充（第二章） | 填充性语气词全部删除；**仅疑问句句尾"呢/吗/呀"保留**（删除会改变句式：疑问→陈述）；**感叹句尾"呢"删除**（单纯口语词，删除不影响理解）；**AI漏听语气词不补回**（见 2.6） |
| ④ | 标点清除 | 除书名号外全部清除；文本行数字内千分位逗号删除（第三、六章） | 无标点残留 |
| ⑤ | 书名号添加 | 作品名添加《》，非作品名不加（3.4） | 作品名已加 |
| ⑥ | 代词核查 | 指代追踪三步法逐一核查"他/她/它"及复数（第四章）；**同音不可区分——转写默认用字不作依据，每个代词按指代对象独立判断（4.9）**；动物/事物一律"它"、泛指人类不冗余加代词、"其它"统一为"其他"；**完成后做全文用字一致性终检（4.11）** | 使用准确、全文一致 |
| ⑦ | 语序修正 | 语序颠倒/成分残缺/杂糅（第五章） | 通顺完整 |
| ⑧ | 数字统一 | 精确值阿拉伯、固定表达汉字、大写仅防篡改（第六章） | 写法统一 |
| ⑨ | 空格隔写 | 并列词逐一隔写、停顿处加空格（第七章） | 隔写完整 |
| ⑩ | 复核输出 | 按第十三章检查清单复核；结构未动；输出到正确文件夹（第十二章） | 交付 |

> **二次校对允许重新断句拆条**：过碎的拆句（同一句完整语义被拆成的多个短条目、尤其≤5字孤立语块）可合并为一条（合并后≤17字、时间码合并为该句语音起止；**仅限同一说话人自己的话，不同说话人的话即使都很短也绝不合并且，见 10.2 第10条**）；长句断句有问题（断点落在语义中途/意群割裂/语序错乱）可重新拆分合并（拆点取语音停顿/意群边界、偏正短语不拆）；**发现一条字幕内混入两人对话（AI 把接话紧密的不同人发言凑成一条）时，按说话人切换点强制拆开、各自独立时间码（见 10.2 第10条）**；**任何一条字幕只有一行文本、不超过17字（17是上限不是目标，不换行）**；未涉及合并/拆分的条目，序号、时间码、空行保持原样。
> **每处修改须能指出规则依据**：修改说明表中每项修改对应规则章节（如"【口语词】删除'嗯'，依据第二章"）；找不到规则依据的修改不做，避免主观过度修改，保证校对准确度。
> **两次校对的分工**：工作方式一只有"生成 → 二次校对"两段，错字依据 = 转写语音 + 语境 + 查证；工作方式二有"初步校对 → 二次校对"两段，初步校对解决"字幕 vs 语音"（错字、隔写、结构标记），二次校对解决"字幕 vs 规范"（口语词、标点、书名号、代词、语序、数字、空格复核），互不重复、互不回退；工作方式三只有"二次校对"一段，直接以原字幕SRT为校对对象，错字等文字问题完全依赖语境判断与查证（上下文互证、外部资料），查证后仍不确定的标注"⚠️ 请确认"。
> **口音/方言分辨（二次校对必做，位于②错字校对内）**：无论哪种工作方式，二次校对都要先**辨别说话人的方言归属（哪一地区方言）**——识别音变特征（平翘舌/nl/hf/前后鼻音/儿化等）与方言词；有口音则按该方言音变规律强化识别——按音位批量排查系统性错字、整词还原（同系列方言误听档案直接复用），方言词保留、不强行翻译成普通话；工作方式二可结合第一阶段实际语音（回听原音），工作方式三完全靠语境判断；**工作方式一/二（有视频）在音频无法确定用词时，定位到该时间点查看视频画面有无相关文字显示进行核对**——画面文字（PPT/图表/字幕条/片头片尾/实物包装文字等）是确定性依据（详见第一章 1.5.3 步骤5），存疑一律标注"⚠️ 请确认"（详见第一章 1.5）。
> **繁简统一（二次校对必做，位于①通读理解内）**：**默认输出简体**——Whisper 系模型转写常默认输出繁体（训练数据繁体占比高，`language="zh"` 不区分繁简），转写完成后**一律执行一次 OpenCC `t2s` 繁→简字符转换**；输入 SRT 为繁体时同样先转简体再校对；**发现繁体绝不重新转写**（重转结果不可控），直接字符级转换（详见第一章 1.6）。

## 一、错字校对规则（【错字】）

### 1.1 同音字/近音字错误（最常见）

AI语音识别最容易把同音词写错，校对时结合语境判断：

| 常见错误 | 正确写法 | 判断依据 |
|---------|---------|---------|
| 反应 / 反映 | 按语境区分 | 化学/生理反应用"反应"，情况上报用"反映" |
| 具体 / 举体 | 具体 | 口语中几乎都是"具体" |
| 毕竟 / 必竟 | 毕竟 | —— |
| 竟然 / 竞然 | 竟然 | —— |
| 即使 / 既使 | 即使 | —— |
| 既然 / 即然 | 既然 | —— |
| 以为 / 已为 | 以为 | —— |
| 再 / 在 | 按语境区分 | "再次"用"再"，"正在"用"在" |
| 的地得 | 按语法区分 | 定语用"的"（美丽的风景），状语用"地"（快速地跑），补语用"得"（跑得快、恢复得、说得不对、填得多） |
| 做 / 作 | 按习惯搭配 | 做实验、做研究；作用、作业、操作 |
| 定 / 订 | 按语境区分 | 预订/订购/订阅用"订"（预订课程、订购器材）；确定/决定/固定用"定" |
| 爆满 / 报满 | 按语境区分 | 报名人数满额用"报满"（名额报满）；人气爆棚用"爆满"（现场爆满） |

### 1.2 科普术语识别错误

- 术语被AI写成同音字时，按科普语境还原（如"光合作用"误为"光和作用"）。
- **近音真实存在的术语要结合语境判断（人工校对高频项）**：AI 可能把生僻术语写成另一个真实存在但读音相近的词——如访谈讲"聚酰亚胺"（高性能工程塑料）时 AI 误写为"聚酰胺"（尼龙类材料），两者都是真实材料、读音接近，**必须依据上下文（材料用途、特性描述）判断正确术语后修正**，不能因为"两词都存在"就保留。
- **不确定的术语不擅改**，标注"⚠️ 请确认"。

### 1.3 人名地名

- 人名（尤其受访者/嘉宾名）被AI写错时，若上下文能确认正确写法则改正；否则标注"⚠️ 请确认"。

### 1.4 专有名词/专业用语/指代名词查证为先（必须）

涉及以下三类内容的修改，**必须先查证正确用字，再决定是否修改**，不得凭印象或"看起来像"直接改：

| 类别 | 涵盖范围 | 示例 |
|------|---------|------|
| 专有名词 | 人名、地名、机构名、品牌名、作品名、朝代名 | 爱因斯坦、珠穆朗玛峰、中国科学院、iPhone、秦始皇 |
| 专业用语 | 科普术语、学科概念、单位符号、公式名称 | 光合作用、相对论、光速、摄氏度、DNA |
| 指代名词 | 承载指代功能的称谓/代词及其指代对象 | 受访者姓名、"这位科学家""该理论" |

**查证手段（按优先级）**：

1. **上下文互证**：同一字幕/视频中该词多次出现时，以多数一致的正确写法为准（如"引物""引勿"并存时查语境确认）。
2. **视频语音复核（视频模式）**：回听原音，以实际发音与语境为准（faster-whisper 转写稿本身可能有误，需听原音复核）。
3. **画面文字核对（视频模式）**：**音频无法确定用词时（口音歧义、术语/人名/药名等专有名词不确定、音频模糊），定位到该时间点暂停/逐帧查看画面，寻找画面中显示的相关文字**——PPT/课件文字、图表标注、节目自带字幕条/标题条、片头片尾文字（人名/机构名）、实物包装文字（药盒/成分表/说明书）、背景文字等；**画面明确显示该词的正确写法时以画面为准**（如画面上打出"麦角硫因"而音频含糊，以画面文字为准确认），画面核对确认的修改标注【画面核对】（见 1.5.3 步骤5）。
4. **外部资料查证**：联网检索官方/权威写法——人名按本人或官方媒体报道用字，术语按学科规范用字，作品名按正式出版/发布名称，机构名按官方名称。

**处理原则**：

- **查证前不改**：无法确认正确用字时，标注"⚠️ 请确认"，保留原字，不擅改。
- **查证后修改**：确认正确写法后，按错字规则修正，并在修改说明表【错字】中注明查证依据（如"以官方报道写法为准"）。
- **指代名词同法**：第四章代词修改中涉及的人名、称谓、机构名等指代对象，同样先查证再判断"他/她/它"用字。
- **人名修正须多源交叉验证（人工校对反馈，重点）**：人名修改**至少经两个独立来源（检索结果/原音回听/画面文字/上下文重复出现）相互印证**后才可确认；**仅凭一次搜索结果的"近似姓氏"就大改人名，是高风险操作**。教训实例：原转写"尼永松"→AI 按常见姓氏误改"汪胜松"→实际应为"倪永松"（只把"尼"→"倪"即可）。**修正幅度越大越要谨慎**——转写音与正确写法高度吻合时（尼→倪），只需小修；转写音与猜测写法差异大时（尼→汪），必须回听原音/查证确认，无法确认则保留原样标注"⚠️ 请确认"。
- **过度修正警示（重点）**：AI 校对最大的风险之一是**把本来只有单字误差的转写改成完全不同的词**——校对时若修改后的词与原转写差异明显大于单字同音范围（"尼永松"→"汪胜松"、"杨永宏"→猜测成其他姓），**先怀疑自己在过度修正**，回到原音/画面/检索核实，而不是顺着错误方向继续猜。
- **"自信地错"警示（人工校对反馈 2026-08，重点）**：《幸福来敲门》对比分析显示，AI 校对稿 1323 处错误中仅 1 处走了"⚠️ 请确认"流程，其余全部是**自信地错**——尤其是专有名词（副总→傅总、禧兰羊→享佳）与数值（18倍→1.8倍）两类。**专有名词与数值是"看起来确定、实际高发错误"的区域**：凡涉及人名/称谓/品牌/地名/品种/卡种/倍率/百分比，即使第一感觉"很确定"，也必须核对所属系列词表（1.7 系列专有名词词表机制）或查证后再定；宁可多标一个"⚠️ 请确认"，不可凭印象放过。

### 1.5 口音与方言导致的语音识别错误（人物口音误判，人工校对高频项）

> 受访者（尤其方言区、少数民族地区、年长者）说话带口音或使用方言时，AI 语音识别会按标准音猜测同音/近音词，产生**整词替换型错误**——不仅单字写错，而是把整个词语替换成另一个读音相近但意义完全不同的词，甚至凭空多出/漏掉字。这类错误**从字面上看不出破绽**（每个字都是真实存在的字），必须靠**语境通顺度**发现。校对时遇到"句子读不通、语义奇怪、出现生僻但无实义组合"的文本，应怀疑口音误判，结合上下文还原说话人本意。**口音影响往往不是零散的而是系统性的**（见 1.5.1）——识别出说话人的口音特征后，可按音位批量排查同类错字。**遇到口音先辨别是哪个地区的方言口音，按该方言音变规律强化识别，再对不确定的内容再次核实修改（三步闭环，见 1.5.4）。**

**典型模式（藏区人物口音实例）**：

| 口音误判（AI 转写） | 正确写法（人工校对） | 误判特征 |
|------|------|------|
| 染染形意 / 形意 | 行医 | "行医"的"行"在口音中近"形"，且被重复误写为"染染"（疑为口音连读/回声误判） |
| 没有灯 | 煤油灯 | "煤油"（méi yóu）被误听为"没有"（méi yǒu），近音+常见词优先误判 |
| 双倍起习 | 双培体系 | "双培体系"（藏医培训体系）为生僻术语+口音，被拆成两个常见词"双倍""起习" |

**判断与处理要点**：

1. **语境不通顺是第一信号**：句子在当前位置读不通（缺宾语、语义矛盾、修饰词与中心词不搭），优先怀疑口音误判而非字面意思。
2. **整词还原而非单字修改**：口音错误往往涉及**整词替换**（"没有灯"→"煤油灯"是 3 个字全部替换），不是单字同音改错；按"说话人本意是什么词"整体还原，而不是逐字猜字。
3. **生僻词/术语优先怀疑**：涉及术语、行业词汇、地名、人名时（如"双培体系"），AI 更倾向写成常见词，结合上下文（如"按恩师的双培体系练出来的"——恩师+练→培训体系）还原。
4. **重复字/叠字警惕**：口音连读或回声可能导致字被重复（"染染形意"），正确写法往往是不重复的（"行医"）。
5. **保留判断底线**：还原后语义通顺、与上下文契合才修改；仍无法确认的标注"⚠️ 请确认"，不凭想象乱改。
6. **工作方式二/一（有视频）时回听原音**：口音误判无法从上下文确认时，回听原音片段，以实际发音为准（faster-whisper 对带口音语音误判率更高，更需原音复核）；**回听仍无法确定用词时，定位到该时间点查看视频画面有无相关文字显示进行核对**——画面文字是确定性依据（见 1.5.3 步骤5）。

#### 1.5.1 常见方言音变导致的系统性错字（重点）

口音对识别的影响是**系统性的**——某方言区的人在特定音位上普遍发不准，AI 按标准音转写时就会在该音位上**成批出错**，形成同一音位的反复错字。校对时先识别说话人的口音特征，再**按音位批量排查**，比逐个碰运气更有效：

| 口音特征（音位） | 常见方言区 | 高发错字方向 | 典型例子 |
|---------|-----------|------------|---------|
| 平翘舌不分（zh/ch/sh ↔ z/c/s） | 南方大部（吴语/粤语/闽语区）、东北部分 | "是"写"四"、"知道"写"资道"、"老师"写"老丝" | 按语义定"是/四"、"十/四" |
| n/l 不分 | 四川、重庆、湖南、湖北、江西 | "哪里"写"拉里"、"牛奶"写"流奶"、"拿"写"拉" | 按语义定"男/蓝"、"你/里" |
| h/f 不分 | 福建、江西、湖南部分 | "花"写"发"、"回家"写"肥家"、"会"写"费" | 按语义定"花/发"、"会/费" |
| 前后鼻音不分（in/ing、en/eng、an/ang） | 南方大部 | "金银"写"金英"、"神圣"写"神胜"、"安全"写"安前" | 按语义定"心/星"、"因/应" |
| 儿化音/轻声异常 | 北方方言（北京、河北、东北） | 儿化词多字/漏字、轻声词写错 | "这儿""明儿"多出或漏掉"儿" |
| 入声/短促收音 | 吴语、粤语、闽语、客家话 | 词尾字漏写/多写、双字词吞成单字 | 句末助词丢失、双字词写单字 |

**排查方法**：

1. **辨别方言归属并识别口音特征**：遇到口音先判断是哪个地区的方言口音（音位特征组合+高频方言词+节目地域背景交叉印证，见 1.5.4 速查表），再留意说话人反复出现的音变规律——同一音位的字被多次写错（如"是"多次写成"四"）即是线索；读不通、语义怪、无实义组合处优先怀疑口音误判。
2. **按音位批量排查**：识别出特征后，把该音位涉及的字**成批检查**——n/l 不分就把全文"n/l"声母的字过一遍，前后鼻音不分就把 in/ing、en/eng、an/ang 的字过一遍，而不是只改碰到的几个。
3. **结合语境还原**：口音错字最终靠**语义**判断正确用字（整词还原、还原后须通顺），不能只按"标准音"机械猜字；还原后仍不通顺或无法确认的标注"⚠️ 请确认"。

**徽州/皖南方言误听模式（人工校对反馈，安徽中医药文化纪录片系列 2026-08 确认）**：徽州方言（祁门/歙县一带）口音导致 Whisper 出现**成批的整词替换型误听**——不只是单字错，而是整个词甚至短语被听成完全无关的常见词。同系列视频校对时按以下模式**批量排查**：

| 方言特征 | 误听方向 | 典型案例（专家误听 → 人工还原） |
|---------|---------|-------------------------------|
| 鼻音/n-l 混淆 | "蛇"→"手"、"十"→"吃食"、"那"→"那还" | "手没给打死"→"蛇没给打死"；"吃食的"→"十粒" |
| 前后鼻音不分（in/ing、an/ang） | "凉"→"黏"、"很"→"还" | "伤又很黏"→"真的很凉"；"那还厉害的"→"那很厉害的" |
| 入声/短促收音吞音 | 整词被听成无意义音节组合 | "散性罗中"→"三斤多重"；"有五色腰疹"→"五步蛇咬伤的" |
| 声调混淆 | 单字替换 | "狗出来"→"勾出来"；"挖茶壳"→"挖茶棵" |
| 韵母混淆 | 整词替换 | "奇竹"→"祁术"；"千年人参"→"千年仁术"；"去风"→"祛风" |
| 介音丢失/音节塌缩 | 术语整词替换 | "CCD里面"→"栖息地里面"；"追心的话"→"竹叶青的话"；"网络样子"→"网络药理学" |

> **排查口诀**：整句读不通、无实义音节组合、与上下文（蛇伤/中药/医学）明显无关的词，**优先怀疑方言整词替换**，按语境整词还原（"五步蛇咬伤""栖息地""竹叶青""祛瘀散"），还原后通顺才改；仍无法确认的标注"⚠️ 请确认"，不凭想象乱改。

#### 1.5.2 方言用词处理原则

口音之外，方言区说话人还会使用**方言词汇**（"晓得"=知道、"冇"=没有、"搞"=做、"咋个"=怎么、"恁"=那么）。处理原则：

- **方言词不是错字，不强行翻译成普通话**：字幕记录说话人实际说的话，方言词承载原意与表达风格，**保留原词**，不改成普通话同义词。
- **AI 把方言词写成同音错字时还原**：说话人实际说的是方言词、AI 却写成同音/近音的其他字时（如"晓得"写"小的"），按语境还原为说话人实际用的词。
- **方言词与普通话语义冲突时按语境定**：同一词在不同方言中语义可能不同（如粤语"细"=小、"走"=跑），以说话人实际表达的意思为准，不套普通话理解硬改。
- **无法判断时标注"⚠️ 请确认"**，不凭猜测翻译。

#### 1.5.3 口音/方言字幕的主动应对流程（工作方式一/二/三）

1. **转写前辨别方言归属（工作方式一/二）**：用户提示视频含方言/口音，或转写前预览判断口音较重时，**先按口音特征与方言词线索辨别说话人是哪个地区的方言口音**（西南官话/东北/吴语/粤语/闽语/客家/湘语/中原官话/藏区等，见 1.5.4 速查表），能确定则**直接按该方言音变规律针对性排查**；辨别依据不足时再询问用户（如"受访者是四川口音吗？"）；用户不便回答时按通用规则排查。
2. **转写参数可选（工作方式一/二）**：方言/口音较重时，可尝试**更大的 whisper 模型**（medium/large-v3）提升转写准确度；若误差仍过大，明确告知用户"该段方言过重、转写误差大，建议在剪映端使用方言识别功能或人工重点复核该段"。
3. **口音修改清单化**：口音类修改主观性最强，**修改说明表中单独标注【口音】类型**（见第十二章修改类型），与【错字】区分，方便用户快速复核；存疑处一律标注"⚠️ 请确认"。
4. **工作方式三（仅SRT，无音频）**：完全靠语义与上下文判断口音错字——能结合语境还原的还原（如"没有灯"→"煤油灯"式整词还原），无法确认的标注"⚠️ 请确认"，不凭想象乱改。
5. **画面文字核对（视频模式，工作方式一/二）**：**音频无法确定用词时——口音导致同音/近音歧义、术语/人名/药名/机构名等专有名词不确定、音频模糊或转写与上下文冲突——定位到该时间点暂停/逐帧查看画面，寻找画面中显示的相关文字**：PPT/课件文字、图表标注、节目自带字幕条/标题条（人名、机构名、栏目名）、片头片尾文字（制作单位、主持人名、嘉宾名）、实物包装文字（药盒、成分表、说明书）、背景文字/横幅/logo 文字等。**画面明确显示正确写法时以画面文字为准**（如画面上打出"麦角硫因"而音频含糊，按画面文字确认写法），此类修改在修改说明表中注明"经画面文字核对"并标注【画面核对】。**画面无相关文字、或画面文字与语境冲突时（画面本身可能打错字），不强行采用**——回到回听原音/上下文互证/外部资料查证，仍不确定的标注"⚠️ 请确认"。画面文字核对是"音频之外的第二个证据源"，只用于音频无法确定的用词，不替代语音比对。

#### 1.5.4 方言口音辨别与强化识别闭环（遇到口音时执行，重点）

> 遇到讲话带口音时，按"**先辨 → 强化 → 核实**"三步闭环处理，避免方言辨别不准导致按错误音位排查、错字越改越乱。

**第一步：辨别方言归属（先辨）**——遇到口音，**先判断说话人是哪个地区的方言口音**，再开始排查错字；方言不同、音变规律不同，辨错方言会导致按错误音位排查。辨别线索（多线索交叉印证，不单凭一个特征）：

| 线索 | 指向方言区 | 典型表现 |
|------|----------|---------|
| 儿化音重+轻声多 | 北方方言（北京/河北/东北） | "这儿""明儿"多出或漏掉"儿" |
| n/l 不分 | 西南官话（川渝云贵）、湘、鄂、赣 | "哪里"写"拉里"、"牛奶"写"流奶" |
| h/f 不分 | 闽、赣、湘部分 | "花"写"发"、"回家"写"肥家" |
| 前后鼻音不分 | 南方大部 | "金银"写"金英"、"神圣"写"神胜" |
| 入声/短促收音 | 吴、粤、闽、客家 | 词尾字漏写、双字词吞成单字 |
| 方言词"咋个/啥子/晓得/安逸" | 西南官话（川渝云贵） | "咋个办""啥子东西" |
| 方言词"中/恁/咋啦" | 中原官话（河南/山东部分） | "中不中""恁大" |
| 方言词"唠嗑/整/得劲儿/咋整" | 东北话 | "唠嗑""咋整" |
| 方言词"阿拉/啥事体/白相" | 吴语（上海/浙江/苏南） | "阿拉上海人" |
| 方言词"冇/唔/嘅/系/咗" | 粤语（广东/广西部分） | "冇问题""唔系" |
| 方言词"么子/何解" | 湘语（湖南） | "搞么子" |
| 方言词"涯（我）/食/冇" | 客家话 | "涯系客家人" |

另有**节目地域背景**线索：拍摄地、受访者籍贯/身份（当地医生/农民/手艺人）、栏目定位（地方台/方言节目）与人物口音互相印证。判断依据不足时标注"疑似 XX 方言"并在修改说明表备注，不硬下结论。

**第二步：方言识别强化（强化）**——辨别出方言后，**用该方言的发音对应规律强化识别**：

- **调取该方言音变规律**：按该方言的音位特征**成批排查**系统性错字（见 1.5.1 音位表：平翘舌/nl/hf/前后鼻音/儿化/入声等），把该方言高发错位在同一份字幕里**全部过一遍**，不留漏网；
- **建立/复用方言误听档案**：本系列**首次**遇到某方言时，把校对中**确认的误听模式**记入修改说明表（方言名称+音位特征+误听→还原案例，如 1.5.1 徽州/皖南方言误听表），**同系列后续内容直接复用**、不再重复推断；**已有档案的方言**（如徽州/皖南、藏区）直接按档案批量排查，并把新确认案例补充进档案——识别能力随人工校对反馈持续强化；
- **档案未覆盖的方言**：按 1.5.1 通用音位表排查，确认案例即时补记。

**第三步：再次校对核实（核实）**——对**之前不确定/存疑的词汇**，在方言强化后用该方言发音规律**再次核实**：

- **方言回读验证**：把候选正确词按该方言的发音方式读出来，与转写音比对——吻合度高的候选优先（如徽州方言"蛇"读近"手"，则"手没给打死"→"蛇没给打死"成立；西南官话 n/l 不分，则"拉里"→"哪里"成立）；
- **上下文互证**：核实后的词放回原句，语义通顺、与前后文（术语/主题/人物身份）契合才改；
- **画面核对/回听原音**：仍有歧义时按 1.5.3 步骤5（画面文字为确定性依据）/ 1.5 判断要点6（回听原音）处理；
- 核实通过但把握不高的修改，修改说明表标注"经方言回读核实"；**仍无法确认的标注"⚠️ 请确认"**，不凭想象乱改。

### 1.6 繁体/简体统一（繁转简，所有模式必做）

> **背景（人工反馈高频问题）**：Whisper 系语音识别模型（faster-whisper 等）的训练数据中**繁体中文占比高**（书籍、百科、网络文本），`language="zh"` 参数只指定"中文"、**不区分繁简**——因此转写结果**经常默认输出繁体字形**（如"这/為/後/們"），尤其在常见字上高发。这是模型固有行为，不是参数没设对。**修复手段是转写后强制做繁体→简体字符转换，而不是重新转写**（重转是概率性输出、两次结果可能不一致，且浪费一次推理；繁→简是确定性字符级映射，一次转换即可）。

**核心原则**：

1. **默认输出简体**：交付的字幕文件统一为简体中文（剪映大陆版、国内科普节目场景）。**除非用户明确要求保留繁体**（如港澳台出版物、正式文件、用户特别说明），才保留繁体。
2. **转写后强制繁转简（工作方式一/二，必做）**：faster-whisper 转写完成后，**无论转写结果是繁体还是简体，都统一执行一次繁体→简体字符转换**，确保转写稿为简体后再进入断句/比对流程——不能只"发现繁体才转"，要**无条件转换**（简体文本经转换后不变，无副作用）。
3. **检测到繁体绝不重转**：发现转写稿含繁体时，**禁止重新转写**（重转结果不可控），直接对现有转写稿做字符级繁→简转换。
4. **输入繁体字幕同样转换（工作方式三/二，必做）**：用户提供的 SRT 若本身是繁体（港澳台来源字幕、旧字幕、繁体剪映模板导出），**二次校对前先把文本行统一转为简体**，再按正常流程校对；序号、时间码、空行、条目结构不受影响。
5. **转换工具（OpenCC t2s）**：优先使用 OpenCC 的 `t2s`（繁→简）转换——本机 Python 环境已安装（`opencc-python-reimplemented`）：
   ```python
   from opencc import OpenCC
   cc = OpenCC('t2s')          # t2s: 繁体→简体
   text_s = cc.convert(text_t) # 逐条/整文件转换文本行
   ```
   - 转写稿转换：对转写结果每条文本调用 `convert` 后进入断句/比对；
   - SRT 文件转换：**只转换文本行**（序号行、时间码行不转换、原样保留），条目结构不变。
   - 若无 opencc：降级用内置繁简对照表做字符级替换（可参考本机 `video-subtitle-tool` 技能的繁转简逻辑），**不要用 LLM 逐句"翻译"繁体**——字符级转换才保证确定性、不改变语义。
6. **转换是"字形归一"不是"内容翻译"**：繁转简只改汉字字形（這→这、為→为、後→后），**不改词语、不改语义**；人名、地名、术语在简体字幕中同样按简体字形输出（"張三"→"张三"、"臺灣"→"台湾"、"細胞"→"细胞"）。
7. **存疑标注**：繁体转换后若出现明显异常（如转换后产生歧义词），结合语境判断；无法确认的标注"⚠️ 请确认"。修改类型标注【繁简】。

### 1.7 系列专有名词词表管理机制（建立/使用/更新，动态）

> **目的**：每个节目/系列维护一份**专有名词词表**，把历次人工校对确认过的正确写法沉淀下来，**后续校同一系列时直接采用、不再重复查证**，并随每次人工校对反馈持续补录新确认的专有名词错误——形成"越校越准"的专有名词记忆。词表以**独立文件**存储（见 1.7.1），可动态新建与更新，区别于写死在规则里的静态示例。

**1.7.1 存储位置与文件格式**

- **位置**：`skills/subtitle-proofreader/references/glossaries/<series-slug>.md`（每个系列一个文件，<series-slug> 为系列名拼音 slug，如 `shiyang-youfang.md`）。

- **配套模板**：`references/glossaries/_TEMPLATE.md`。

**1.7.2 系列识别（校对开始时确定）**

- 校对启动后，**先确定当前节目所属系列**——以用户提供的节目/系列名为准（如"食养有方第12期""安徽中医药纪录片""幸福来敲门"）；用户未明说时，从节目文件夹名、片头/栏目名、主题领域推断，推断不确定则**向用户确认一次**系列归属，不臆测。

**1.7.3 建立（新节目/新系列首次校对）**

**1.7.4 使用（校对时加载并直接采用）**

**1.7.5 更新（每次人工校对反馈后补录/修订）**

### 1.8 回声式重复/幻觉内容检测（人工校对反馈，2026-08 确认，重点）

AI 转写长音频时常出现**回声式重复**——把前文已出现的句子再次插入当前位置（转写幻觉），插入处与前后文语义不连贯。《幸福来敲门》人工校对已确认多例：

| 位置 | AI 稿插入的重复句（幻觉） | 人工稿正确内容 |
|------|------------------------|---------------|
| 15:16 | "我就是活多久我就得喝多久"（重复前文） | "一个有钱的开了个保时捷的老头" |
| 12:52 | "因为可能我对这个羊奶跟老人的活力" | "我给大家总结一下大白话" |
| 13:58/14:07 | "协和的一个大教授"（重复两遍） | "我们有时候老关心病怎么治" |

**检测方法**：逐条校对时，若当前条目内容与**前文（约前后 1-2 分钟内）已出现的句子高度相似或完全相同**，且上下文语义不连贯（前句讲 A、此句突然重复旧句、后句直接接 C），判定为疑似回声幻觉。

**处理方式**：

1. **有视频（工作方式一/二）**：回听该时间点原音，按真实语音还原正确内容；修正后标注【语音比对】并注明"剔除回声重复"。
2. **无视频（工作方式三）**：标注"⚠️ 疑似转写重复 请对照原音确认"，保留原文不擅删（无音频依据时无法得知真实内容）。
3. **回声重复与有意重复的区分**：说话人**有意强调**的重复（紧接着原句再说一遍、语义连贯）是正常口语，保留；**跨时间距离**（隔了多个话题后突然重现旧句）且语义断裂的才是转写幻觉。

## 二、口语用词清理规则（【口语词】）

### 2.1 语气词/叹词：一律删除（不保留）

以下语气词**无论出现在句首、句中、句尾，一律删除**：

- **叹词/语气填充**：嗯、啊、哦、哎呦、呐、呀、哈、咿、哎、唉、喂、呃、哎呀、诶、哇、咦、咳、嗨、呵、啰、嘞、呗、嘛、哟、嚯、啧
- **应答/重复填充**：嗯嗯、啊啊、对对、对对对、是是、是是是、好好好（口语填充时）——**二字重复应答（对对/是是/好好）同样删除**（人工校对反馈：二字应答词"对对""是是"也属口语填充，一律删除）
  > **分歧裁决记录（2026-08-28 用户确认）**：《幸福来敲门》人工校对稿曾保留 166 条单字应答独立成条（"对""是""太好了 太好了""太棒了""愿闻其详"），与本条"一律删除"冲突；经用户裁决**维持一律删除不保留**，后续校对仍按本条执行，不再因该人工稿保留应答词。

> **应答用语气词（重点）**：回答问题时**句首的应答填充**——"嗯，我觉得……""啊，是这样的""哦，原来如此"中的"嗯/啊/哦"——是典型应答口语词，**一律删除**，直接进入正式回答内容（"我觉得……""是这样的""原来如此"）。"哦"出现在"哦，原来如此"等感叹应答语境时同样删除。
> 例外1：句末疑问助词**"吗"**承载疑问语义（如"你知道吗"），删除会改变句意，**保留**；**例外2：固定疑问词中的"嘛/吗"是词干组成部分，不是语气词，一律保留**——如**"干嘛/干吗"**（"做什么"义，"你在干嘛""你在干吗"），其中的"嘛/吗"是词干、不得删除；"呢"在句尾表达疑问句时保留、不删除（如"你觉得呢""怎么回事呢""那怎么办呢"中的疑问/追问语气），纯填充时删除。
> **例外3（人工校对高频项，重点）：疑问句句尾的"呀"保留**——"这是为什么呀""你说的到底行不行呀"中"呀"承载疑问语气，**保留**；仅作句首叹词或句中填充的"呀"（"呀 你来了""变快了呀"感叹填充）删除。
> **例外4（人工校对高频项，重点）：句尾"吧"表确认/推测/商量语气时保留**——"就这么定了吧""你说对吧"中的"吧"承载语气，删除会改变语气，**保留**；**"是吧"作口语确认标记一律保留**（"你不能不让人挣着钱 是吧""那就不叫集采了 是吧"）；仅作句首填充的"吧"（"吧 我觉得……"）删除。
> **例外5（人工校对反馈）：感叹句句尾的"呢"删除**——"其实大家都是迫不及待的呢"中"呢"是单纯口语词，删除后句子结构完整、语义不变，**删除**（→"其实大家都是迫不及待的"）；填充性的"呢"（连接词/名词后的"呢"字尾）仍按 2.5 删除。**仅疑问句句尾的"呢"保留**（删除会改变句式：疑问→陈述）。

### 2.2 口头禅/填充词：一律删除（不保留）

- **指示填充（重点）**：这个、那个、这些、那些——**作口头禅、无实际表达指向意义时一律删除**，无论句首、句中、句尾：
  - ❌ 删除："这个，我觉得这个实验挺有意思的" → "我觉得实验挺有意思的"（句首"这个"为无实指填充）
  - ❌ 删除："那个，其实啊，这个原理很简单" → "其实原理很简单"（"那个"为句首填充）
  - ✅ 保留（实指）："这个实验的原理是……"（"这个"实指"实验"，指示具体对象）
  - ✅ 保留（实指）："那个方案不行，换这个"（"那个/这个"有对比指向）
  - **判断标准**：删去"这个/那个"后句意不变、指代关系仍清晰 → 删除；删去后失去指代对象、语义残缺 → 保留。
  - **句中冗余定语的"这个"一律删除（人工校对高频项）**："这个"夹在名词短语内作修饰成分、删除后语义不变时**一律删除**——"刚得**这个**高血压"→"刚得高血压"、"你的**这个**剂量"→"你的剂量"、"看似**这个**衰老"→"看似衰老"、"为**这个**抗体创造良好的**这个**生存环境"→"为抗体创造良好的生存环境"、"降低**这个**患癌的风险"→"降低患癌的风险"、"改善老慢病的**这个**效果"→"改善老慢病的效果"、"搭配对应的**这个**饮食和运动"→"搭配对应的饮食和运动"。此类"这个"是典型口语填充，**宁删勿留**。
  - **句首无实指"这个/那个"一律删除（人工校对反馈，重点）**：句首"这个/那个"作为口语填充词（停顿、思路组织、话语衔接），**删除后句意不变、句子结构完整 → 一律删除**——"**这个**正是我们需要科学抗衰老的原因"→"正是我们需要科学抗衰老的原因"、"**这个**我们现在已经在帮大家去做集采了"→"我们现在已经在帮大家去做集采了"、"**这个**其实没有什么适合不适合的"→"其实没有什么适合不适合的"、"**这个**可是百岁俱乐部"→"可是百岁俱乐部"。**判断标准：删去"这个/那个"后句子语义完整、句意不变 → 删除**；只有"这个/那个"实指前文/身边的某个具体对象时才保留。
- **指示填充的衍生形式（人工校对高频项，一并删除）**：**这么、这样一个、这样一个、这样的话、这种情况、这种**等"指代词 + 泛化名词"组合，**作口头禅、无实指时一律删除**（如"这么弄""这样的话""这种情况"在句中起连接/填充作用时删掉，句子仍通顺且语义不变）：
  - ❌ 删除："然后他就这么一直练" → "然后他一直练"（"这么"为无实指程度填充）
  - ❌ 删除："这样的话 效果会更好" → "效果会更好"（"这样的话"为句首连接填充）
  - ❌ 删除："这种情况我也遇到过" → "我也遇到过"（"这种情况"无实指、指代空洞时删除；若前文确指某种具体"情况"，则保留"这种情况"）
  - **注意"这个/这么"在科普访谈中高频出现**：说话人语速快、思路组织时大量使用"这个/这么"作停顿填充，删除力度要更积极——**无实指一律删，宁删勿留**；只有明确指向前文/身边具体对象时才保留。
- **连接填充**：就是说、也就是说、然后、然后呢、接下来呢、那个那个
- **反问填充**：对吧、是吧、是不是（无实义时）、你懂吧、你明白吗
- **重复词**：同一句话里连续重复的词语（如"就是就是""对对对"）

### 2.3 保留（承载语义的词）

| 词语 | 保留情形 | 示例 |
|------|---------|------|
| 这个/那个 | 作指示代词**实指某物**时（有明确指向对象或对比指向） | "这个实验的原理是……"（实指）；"那个方案不行换这个"（有对比指向，保留） |
| 确实/其实/当然 | 表达强调、转折、认同等语义 | "这确实是个好问题"（保留） |
| 比如/例如 | 引出举例 | 保留 |
| 吗 | 句末疑问标记 | "你知道这个原理吗"（保留） |
| 呢 | 句尾表达疑问句时（疑问/追问语气，删除会改变句式——疑问变陈述） | "你觉得呢""怎么回事呢"（疑问保留）；**填充性"呢"（连接词/副词/名词+呢）一律删除"呢"字**（见 2.5）；**感叹句句尾"呢"删除**（单纯口语词，删除不影响句子结构理解） |
| 呀 | **疑问句句尾**（承载疑问语气） | "这是为什么呀"（保留） |
| 吧 | 句尾表确认/推测/商量语气 | "就这么定了吧""你说对吧"（保留） |
| 是吧 | 口语确认标记（句尾或独立） | "你不能不让人挣着钱 是吧"（保留） |
| 干嘛/干吗 | 固定疑问词（"做什么"义），"嘛/吗"是词干组成部分 | "你在干嘛"（保留，不得删"嘛/吗"） |

### 2.4 删除原则

1. **语气词与口头禅无条件删除**：不因"口语生动性"而保留。
2. **问答结构保留**：主持人问题、受访者回答的分工结构不要打乱。
3. 删除后句子语义完整是底线——若删除导致语义残缺（如实指的"这个"），则保留。

### 2.5 "呢"字尾删除（重点）

口语中常见的"**连接词/副词 + 呢**"句式——**所以呢、其实呢、然后呢、而且呢、可是呢、但是呢、毕竟呢、总之呢、当然呢、不过呢、结果呢、原来呢、的确呢**等——词尾"呢"是口语停顿填充，**一律删除"呢"，保留连接词/副词本身**：

- ❌ "所以呢，这个实验很重要" → ✅ "所以这个实验很重要"
- ❌ "其实呢，原理很简单" → ✅ "其实原理很简单"
- ❌ "然后呢，温度就升高了" → ✅ "然后温度就升高了"
- ❌ "而且呢，效果还很稳定" → ✅ "而且效果还很稳定"
- ❌ "可是呢，数据不太对" → ✅ "可是数据不太对"

**扩展到名词/短语 + 呢（人工校对高频项）**：说话人引出话题、强调对象时，口语常在**名词或名词性短语后加"呢"**停顿——**这次活动呢、这个问题呢、这个实验呢、我们呢、大家呢、这个阶段呢**等，词尾"呢"同样是口语停顿填充，**一律删除"呢"，保留名词/短语本身**：

- ❌ "这次活动呢 也没有能够避免这个情况" → ✅ "这次活动也没有能够避免这个情况"
- ❌ "这个问题呢 其实很简单" → ✅ "这个问题其实很简单"
- ❌ "这个实验呢 我们做了很多次" → ✅ "这个实验我们做了很多次"
- ❌ "我们呢 平时要注意饮食" → ✅ "我们平时要注意饮食"

**判断标准**：删除"呢"后句子语义完整、句子仍通顺 → 删除"呢"；**"呢"在句尾表达疑问句时保留、不删除**（如"你觉得呢""怎么回事呢""那怎么办呢"中的疑问/追问语气——删除会改变句式：疑问→陈述）；**感叹句句尾"呢"删除**（"其实大家都是迫不及待的呢"→"其实大家都是迫不及待的"，"呢"是单纯口语词，删除不影响句子结构理解）。

### 2.6 疑问语气词保留与口语确认词规范（人工校对反馈，重点）

> 人工校对反馈：句尾语气词中，**仅疑问句句尾的语气词承载句式功能（疑问→陈述），必须保留**；感叹句句尾"呢"属单纯口语词，删除不影响句子结构理解，应删除；确认语气"是吧"保留。**不补回 AI 漏听的语气词**——字幕以原文实际语音为准，不主动添加原文未出现的词：

1. **疑问句句尾语气词保留（不补回）**：句尾是疑问语气（"什么意思""为什么""怎么办""会公布价格吗""没机会了"）时，**原文字幕中已有"呢/吗/呀"的必须保留**（删除会改变句式：疑问→陈述）；**AI漏听的语气词不补回**——以原文实际语音为准，不主动添加原文未出现的词：
   - "你觉得呢" → 保留"呢"（删则变陈述句"你觉得"）
   - "怎么回事呢" → 保留"呢"（删则变陈述句"怎么回事"）
   - "明天就会公布价格吗" → 保留"吗"（疑问标记）
   - **AI漏听的"呢/吗/呀"不补回**——以原文实际语音为准，不主动添加
2. **句末单字"是"（确认语气）规范为"是吧"**：说话人句尾单字"是"表确认/反问语气时，**规范为"是吧"**（更符合口语自然度），"是吧"前加空格：
   - "你不能不让人挣着钱是" → "你不能不让人挣着钱 是吧"
   - "那就不叫集采了是" → "那就不叫集采了 是吧"
   - **"是"单独成条作应答时保留单字"是"**：如"是 那对比的结果是51:62"中应答"是"保留。
3. **感叹句句尾"呢"删除**：句尾"呢"表达感叹语气时（"其实大家都是迫不及待的呢"），"呢"是单纯口语词，删除后句子结构完整、语义不变 → **删除"呢"**（→"其实大家都是迫不及待的"）。**感叹句句尾"了"保留**（"那千万也别错过"中"了"若为动词完成体则按语义保留）。
4. **叠字/重复修正（引述结构）**：AI 常把引述结构"说了+说"合成叠字"说了说"——还原为"说了"（上一条）+ 下一条以"说"开头（"比如有家人说了"+"说他的冠心病……"）；"是 是"等重复应答规范为单个（"是 是 你既要兼顾"→"也是"+"你既要兼顾"）。

## 三、标点符号清除与书名号添加规则（【标点】【书名号】）

### 3.1 全部清除（书名号除外）

删除文本中**除书名号外的所有标点符号**，字幕文本只保留汉字、数字、字母、书名号与必要的空格：

- **句末标点**：句号。、问号？、叹号！
- **句中标点**：逗号，、顿号、分号；、冒号：
- **成对标点（书名号除外）**：引号""''、括号（）[]、书名号《》（**保留**，见 3.4）
- **其他**：省略号……、破折号——、间隔号·
- **英文标点**：`, . ! ? : ; " ' ( )` 同样清除

### 3.2 保留（非标点符号）

- **时间码行**：序号行与时间码行（含冒号、箭头）不属于文本内容，原样保留。
- **数值符号**：小数点（3.14）、百分号（50%）、正负号（-5℃）、科学单位（km/h）——这些是数值/单位的一部分，不是标点，保留。
- **书名号《》**：作品名称的语义标识，**不删除**；且字幕中提及的著作、文章等作品名**需要主动添加**（见 3.4）。
- **必要的空格**：数字与单位之间的空格保留；**空格隔写见第七章规则**。

### 3.3 修改示例

```
修改前：温度升高之后，反应速率会明显加快。这是为什么呢？
修改后：温度升高之后反应速率会明显加快这是为什么呢
```

```
修改前：他最近读了时间简史这本书，还写了一篇关于黑洞的文章。
修改后：他最近读了《时间简史》还写了一篇关于黑洞的文章
```

> 逗号、句号、问号全部删除；"为什么"的疑问语义仍由原文"呢"承担（"呢"此处为疑问助词，可保留）；**作品名"时间简史"添加书名号《》**；"这本书"为同位语填充一并删除；"关于黑洞的文章"为泛称（不确指作品名）不加书名号。

### 3.4 书名号添加规则（【书名号】）

标点清除的唯一例外：**书名号《》承担标识作品名称的语义功能，不删除；且字幕中提及的作品名需要主动添加书名号**。

**需要添加书名号的（作品类）**：

| 类别 | 示例 |
|------|------|
| 书籍/著作 | 时间简史 → 《时间简史》 |
| 文章/论文 | 他发表的论文 黑洞的成因 → 论文《黑洞的成因》 |
| 影视/节目 | 流浪地球、走近科学 → 《流浪地球》《走近科学》；**节目/栏目名同样加书名号（人工校对反馈 2026-08 确认）：《幸福来敲门》《魔戒》等，本节目自报名与受访人提及的影视作品均加** |
| 歌曲/乐曲 | 我和我的祖国 → 《我和我的祖国》 |
| 戏剧/戏曲 | 雷雨、茶馆 → 《雷雨》《茶馆》 |
| 报刊/杂志 | 科学杂志、自然杂志 → 《科学》《自然》 |
| 法规/文件 | 著作权法 → 《著作权法》 |
| 诗/词/文学作品 | 静夜思、呐喊 → 《静夜思》《呐喊》 |

**不加书名号的（非作品名）**：

- **人名/称呼**：爱因斯坦、牛顿、张三
- **品牌/产品名**：苹果、特斯拉、iPhone
- **概念/理论/学科**：相对论、量子力学、生物学
- **地名/机构名**：中国科学院、北京
- **活动/会议名**：世界读书日、科学大会
- **泛称**："这本书""那篇文章"（不确指作品名时不加）
- **作品名被用作形容词/比喻/描述性短语**：如"可以用笑傲江湖来形容"——此处的"笑傲江湖"是借用引申义来描述，不是在引用小说《笑傲江湖》本身，**不加书名号**（见 3.4 判断要点 2）

**判断要点**：

1. **确指作品名称才加**：能明确判断为具体作品（有标题属性）时添加；仅泛称"这本书""那篇文章"时不加。
2. **语境判断——作品名被用作形容词/比喻/描述性短语时不加书名号（人工校对反馈高频项，重点）**：当某词虽与作品名同名，但在语境中**不是指代作品本身**，而是作为**形容词、比喻、描述性表达**使用时，**不加书名号**。判断信号词：
   - "用X来形容" / "用X来比喻" → X 是被借用的描述性表达，不加（如"可以用笑傲江湖来形容"→ 保持"笑傲江湖"，**不加**《笑傲江湖》）
   - "X般" / "像X一样" / "如X一般" → X 是比喻素材，不加
   - "称得上X" / "堪称X" → X 是评价性借用，不加
   - "X就是X"（强调概念而非作品本身） → 不加
   - **核心判断标准**：该句是在"讨论/引用/推荐这部作品"（加），还是在"借用该词的引申义来描述其他事物"（不加）。不确定时标注"⚠️ 请确认"。
3. **不确定时标注**：无法判断是否为作品名时，标注"⚠️ 请确认"，不擅加。
4. **书名号后不接其他标点**：书名号是唯一保留的成对标点，其前后不再出现引号、顿号等（如《时间简史》不加引号）。
5. **视频模式**：第一阶段转写语音中出现的作品名信息（说话人明确说出书名/文章名）作为添加依据；转写可能误判，需结合语境确认。

## 四、代词（她/他/它）准确使用修改规则（【代词】）

> 第二阶段规则二次校对的**必查项**：**逐一检查字幕中每个"她/他/它"**（含"她们/他们/它们"），确保使用准确，不放过任何一个。

### 4.1 指代追踪三步法（每个代词必做，单复数同法）

1. **定位**：找出字幕中**所有**"他/她/它"**及复数形式"他们/她们/它们"**，逐一列出，不遗漏。**"他/她/它"及"他们/她们/它们"全部同音（tā / tāmen）——语音与转写引擎无法从读音区分用字，AI 转写默认倾向写"他/他们"，任何沿用转写默认用字而不核查的行为都是错误**；每个代词都必须按指代对象独立判断后定字。
2. **回溯**：从代词位置**向前回溯最近的指代对象**（通常在本句或前一句内；隔句较远时结合整段主题判断；**代词连续多次出现时追踪整条指代链**——同一对象贯穿多句，后续代词沿用同一用字）。
3. **判断**：按指代对象属性决定用字——
   - 指代**单个人**（受访者、主持人、科学家、亲属等）→ 按性别用"他/她"（人名与头衔是性别线索）
   - 指代**多个人/群体**（受访者与主持人、科学家群体、观众、网友等）→ 按对象性别构成用"他们/她们"（**全部为女性才用"她们"，其余用"他们"**）
   - 指代**动物/事物/概念/机构/国家/实验/技术/AI** 等非人称对象 → 一律用"它/它们"
   - **动物即使拟人化也用"它"**：科普叙述中的动物（"这只熊猫""海豚"）即使说话人带有感情色彩、即使已知动物性别（"公狮""母羊"），指代一律用"它/它们"，不改用"他/她"——拟人是修辞，不是代词用字依据
   - **泛指人类/人群不冗余加代词**：主语已是"人类""人们""大家""我们每个人"等集合表述时，后面不再跟"他们/她们"（"人类他们创造了文明"→"人类创造了文明"），删冗余代词标注【代词】

### 4.2 判断标准

| 代词 | 指代对象 |
|------|---------|
| 他 | 男性人物（单个） |
| 她 | 女性人物（单个） |
| 它 | 单个动物、事物、概念、机构、国家等非人称对象 |
| 他们 | 多个男性人物、男女混合群体、性别未知群体，或强调成员个体的多人集合（科学家们、主持人与受访者） |
| 她们 | 全部为女性的群体 |
| 它们 | 多个动物、事物、概念、机构、国家等非人称对象 |

### 4.3 常见AI识别错误（重点核查）

- **"它"误写成"他/她"（最高频）**：AI 对非人称对象误判性别，如"实验他……""技术她……"→ 应为"它"。当指代对象在前文反复出现（如"实验"多次出现）时尤其高发。
- **"它们"误写成"他们/她们"（复数最高频）**：AI 对非人称复数对象误判，如"这些数据他们很准确""细胞她们有修复能力"→ 应为"它们"。
- **"她们"与"他们"混淆**：AI 听写或识别时搞错群体性别构成，需结合群体成员身份确认——**仅当指代对象全部为女性时才用"她们"**（如"几位女科学家她们……"）；男女混合、性别未知或包含男性的群体一律用"他们"。
- **集体名词误判**：指代对象是集体名词（科学家们、观众们、网友们、团队、机构、国家）时，判断其指代的是"人"还是"组织"——**强调成员个体用"他们/她们"**（"科学家们他们认为……"），**强调组织/机构整体用"它"**（"中国科学院它……"）。
- **"它们/她们/他们"同理**：复数形式同样按指代对象判断。
- **代词缺失**：口语省略导致指代缺失（如"……然后温度就升上去了"缺主语"它"），按语境补齐但不新增实质信息。
- **叙述故事中的性别追踪（人工校对高频项）**：科普访谈常穿插举例、故事叙述（"有位患者……""一个家长……"），AI 听写时容易把故事中的**女性角色写成"他"**（或男性写成"她"）——必须**沿叙述链追踪指代对象性别**：故事开头的人名/称谓（"李女士""张阿姨""王医生"）或上下文线索（"她女儿""这位女老师"）即性别依据，**同一人物后续所有"他/她"用字必须前后一致**，不得一会儿"他"一会儿"她"。
- **沿用转写默认用字（系统性错误，最高警惕）**："他/她/它（们）"全部同音，转写引擎无法从读音判断用字、默认倾向输出"他/他们"——字幕里成片的"他"可能大多本应是"它/她/它们"，**绝不能因为"转写写的是他"就默认保留**，每个代词都必须回到指代对象重新判断。
- **"其它/其他"混用（关联用字规范）**：指代事物时规范用字也一律是"其他"，字幕中的"其它"统一改为"其他"（"其它成分"→"其他成分"），标注【代词】。
- **动物拟人化误判**：说话人对动物带有感情色彩的叙述（"这只小猴子他特别聪明"），AI 顺沿拟人口吻写"他/她"→ 应为"它"；动物性别已知（"母羊""公鹿"）同样用"它"。
- **集合表述后冗余代词**："人类/人们/大家/咱们"等集合主语后再跟"他们/她们"属冗余，删除（见 4.1 步骤3）。

### 4.4 问答访谈场景判断要点

- **主持人 vs 受访者**：通读了解问答双方性别——主持人提问中的"他/她"通常指受访者；受访者回答中的"他/她"可能指第三方（如提到的另一位科学家）。
- **多人/群体场景（复数重点）**：访谈常提及"科学家们""研究人员""观众""网友"等群体——**指成员个体时用"他们/她们"**；"科学界""学术界""这个领域"等抽象集合概念用"它"。主持人说"我们""咱们"指代双方时不改（第一人称不受本规则约束）。
- **人名出现处即性别线索**：受访者姓名、头衔（如"王教授""李博士"）帮助确认性别；无法确认性别时保留原文并标注"⚠️ 请确认"。
- **非人称高频对象**：科普访谈中"实验、数据、技术、细胞、地球、AI"等出现频率极高，其指代**一律用"它"**，是本类字幕的重点纠错对象。
- **叙述/举例场景追踪性别**：讲故事、举例子时（"有位患者""有个家长""我认识一位女士"），指代该人物的代词按故事人物性别统一，**整段叙述链中同一人物的"他/她"用字前后一致**；上下文无法确认性别时标注"⚠️ 请确认"。
- **视频模式**：第一阶段转写按音色分段标注 [Q]/[A] 可帮助确认说话人；转写中的代词错误同样在第二阶段按本规则修正。

### 4.5 示例

| 原文 | 修改后 | 说明 |
|------|--------|------|
| 这个实验他其实很有意思 | 这个实验它其实很有意思 | 指代"实验"（事物）用"它" |
| 这位科学家她提出了新理论 | 这位科学家她提出了新理论 | 科学家为女性，保留"她" |
| 机器人他可以帮助人类 | 机器人它可以帮助人类 | 机器人是事物，用"它" |
| 细胞它拥有自我修复能力 | 细胞它拥有自我修复能力 | 指代"细胞"（事物），原已用"它"，确认无误 |
| 主持人 王教授他怎么看这个问题 | 主持人 王教授他怎么看这个问题 | "王教授"为男性，保留"他"（人名即性别线索） |
| AI她学会了写诗 | AI它学会了写诗 | AI 是非人称对象，用"它" |
| 实验数据他们很准确 | 实验数据它们很准确 | 指代"数据"（事物），用"它们" |
| 科学家们他们认为理论可行 | 科学家们他们认为理论可行 | "科学家们"是人（男性或混合群体），保留"他们" |
| 几位女科学家她们提出了新模型 | 几位女科学家她们提出了新模型 | 群体全为女性，用"她们" |
| 细胞她们有自我修复能力 | 细胞它们有自我修复能力 | 指代"细胞"（事物复数），用"它们" |
| 科学界他们普遍认同这个观点 | 科学界它普遍认同这个观点 | "科学界"是抽象集合概念，用"它" |
| 这只熊猫她特别爱睡觉 | 这只熊猫它特别爱睡觉 | 动物即使拟人化也用"它" |
| 免疫力他就像人体的军队 | 免疫力它就像人体的军队 | 指代"免疫力"（生理概念），用"它" |
| 这个产品他们很适合老人 | 这个产品它很适合老人 | 指代"产品"（事物），用"它" |
| 其它成分也很重要 | 其他成分也很重要 | "其它"非规范用字，统一为"其他" |
| 人类他们不断探索宇宙 | 人类不断探索宇宙 | 集合主语后冗余代词，删除 |
| 李阿姨他的血糖控制得很好 | 李阿姨她的血糖控制得很好 | 叙述链人物"李阿姨"为女性，代词用字前后统一 |

### 4.6 处理原则

- **必须逐一核查**：**所有"他/她/它"及"他们/她们/它们"都要过一遍，不能只改明显的**。
- **复数同样必查**："他们/她们/它们"是复数字幕的高频错误区（AI 常把"它们"写成"他们"），逐条核查不遗漏。
- **查证为先**：涉及人名、机构名等指代对象时，先查证正确写法再判断用字（见第一章 1.4）。
- **无法判断时不擅改**：指代对象不明确或性别无法确认 → 标注"⚠️ 请确认"，保留原文。
- **修改类型标注【代词】**：修改说明表中逐条列出"原文 → 修改后 → 代词"。

### 4.7 指代名词查证为先（必做）

代词修改**不是猜字游戏**：判断"他/她/它"之前，先确认**指代对象本身的正确写法**——

- **人名/称谓**：指代对象是人名（受访者、嘉宾、第三方科学家）时，先查证其姓名正确用字（视频模式回听原音确认读音与写法；可联网检索该人物官方写法），再结合性别判断代词。
- **机构/国家/组织名**：指代对象是机构名（"中国科学院""NASA"）时，确认名称正确写法后按"非人称对象 → 它"处理。
- **术语/概念名**：指代对象是专业术语（"引力波""基因编辑"）时，先确认术语正确用字（见第一章 1.4），再判断代词用"它"。
- **查证手段**：上下文互证 → 视频语音复核 → 外部资料（联网检索/词典/权威来源）→ 仍不确定则标注"⚠️ 请确认"。

### 4.8 称谓敬语规范：主持人对嘉宾"你"→"您"（人工校对反馈 2026-08 确认）

**主持人/晚辈对嘉宾/专家/长辈说话时的"你"统一规范为"您"**（敬语化），人工校对高频项（《幸福来敲门》人工校对大量修正）：

- ❌→✅ "你给我们讲讲" → "您给我们讲讲"；"你觉得呢" → "您觉得呢"；"你刚才说的" → "您刚才说的"
- **判断依据**：
  - **改"您"**：说话人为**主持人**且听话人为**嘉宾/专家/长辈/观众群体**（访谈问答场景的提问、致谢、请托）
  - **不改**：嘉宾对主持人说话、平辈之间对话、转述第三人（"他跟你说"）、引用原话
- **修改类型标注【代词】**，修改说明中注明"敬语化"。

### 4.9 同音不可区分与转写默认处理原则（2026-09 强化）

**"他/她/它"与"他们/她们/它们"全部同音（tā / tāmen）**，这是代词校对的根本难点，处理原则：

1. **读音不提供任何用字信息**：语音里听到的 tā 无法判断是"他/她/它"，转写引擎输出的用字纯属默认猜测（统计上偏向"他/他们"）——**转写用字不是证据，指代对象才是唯一依据**。
2. **每个代词独立判断**：逐个回到指代对象（4.1 三步法），判断后定字；**不得以"转写写的是他""前后文都是他"为由批量保留**——前后文的"他"可能同样源于默认错误。
3. **同一段落多个代词指代不同对象时逐个核对**：访谈中"他说……她补充……它指的是……"混排常见，各自回溯各自的指代对象，不串判断。
4. **修改后通读验证**：代词修正完成后将整句/整段连读，确认修正后代词语义通顺、指代清晰，不因改字引入歧义。

### 4.10 高频非人称对象速查（一律"它/它们"）

科普/大健康节目中出现频率极高的非人称对象，指代**一律用"它/它们"**，见到"他/她"直接判错：

| 类别 | 高频对象 |
|------|---------|
| 生理/医学 | 细胞、基因、蛋白质、免疫力、抗体、器官（心脏/肠道/肝脏）、血糖、血压、菌群、病毒、细菌 |
| 营养/食品 | 营养素、维生素、膳食纤维、蛋黄球蛋白、益生菌、成分、配方、食品、产品 |
| 科学/技术 | 实验、数据、理论、方法、技术、AI、模型、设备、仪器、材料 |
| 自然/抽象 | 地球、宇宙、能量、光、水、土壤、概念、观点、问题、结果、现象 |
| 机构/组织 | 医院、公司、团队、机构、国家、行业、领域（强调整体时） |

**动物类**（熊猫、羊、犬等）同样一律"它/它们"（见 4.1 步骤3 拟人化规则）。

### 4.11 全文用字一致性终检（复核输出阶段必做）

代词修正完成后、进入复核输出（第十章 10.2 第10步）前，做一次**全文代词一致性终检**：

1. **同一指代对象全文用字一致**：同一人物/事物在全片字幕中的代词用字必须统一——前文用"它"、后文又变"他"的，按指代对象改正并标注【代词】。
2. **同音音节再扫一遍**：按条目顺序把所有 tā / tāmen 音节再过一遍（含转写中可能漏改的），确认没有漏网代词。
3. **"其它"清零检查**：全文搜索"其它"，统一改为"其他"。
4. **统计与报告**：修改说明表汇总代词修改总数；同一指代对象前后用字不一致的修正，在说明中注明"前后统一"。

## 五、语序修正规则（【语序】）

### 5.1 需修正的语序问题

1. **语序颠倒**：口语中先说结论后补主语/状语，书面化时调正。
   - 原文："原理是，这个实验的，核心在于……"
   - 修改后："这个实验的核心原理在于……"
2. **成分残缺**：缺主语、缺宾语，导致句子不完整。
   - 原文："然后就是，温度升高，就会，嗯，反应更快"
   - 修改后："温度升高后反应会更快"
3. **句子杂糅**：两句话揉在一起。
   - 原文："这个数据我看了觉得可能是采集的问题吧也可能是方法的问题"
   - 修改后："这个数据我看了觉得可能是采集的问题也可能是方法的问题"

### 5.2 修改原则

- **保持原意**：只调整表达，不增删实质信息。
- **科学表述准确**：涉及因果、条件、对比关系时，确保逻辑关系不因语序调整而改变。
- **不加标点（不换行）**：语序调整后不以标点断句、不换行，句子边界与停顿均由空格承担。
- **同步清理**：调整语序的同时，顺带删除该句内的口语词与标点。

## 六、数字书写统一规则（【数字】）

> 第二阶段规则二次校对的**必查项**：逐条检查字幕中所有数字的写法，统一为规范用法——**阿拉伯数字与汉字数字各归其位，同一份字幕内同类别数字写法一致，不混用**。

### 6.1 统一原则

1. **精确数值默认用阿拉伯数字**：年份、日期、时间、度量、百分比、金额、编号、年龄、数量等精确数值，统一使用阿拉伯数字（见 6.2）。
2. **固定表达保留汉字数字**：成语、惯用语、概数、农历节气、朝代、**含数字的固定名称（药品名/产品名/专有名称）**等固定表达中的汉字数字保留，不改写（见 6.3）。
3. **口语叙述中的时间长度/金额倾向保留汉字数字**：说话人**口述的时长、金额、次数**（"行医十二年""十万块钱""走了八年"），是口语叙述的一部分，改阿拉伯数字会破坏语感，**保留汉字数字**；精确的统计值/度量值（"30%""40%""1200人"）仍用阿拉伯数字（见 6.3 分界）。
4. **汉字大写数字（壹贰叁…）仅限防篡改场合**：出现在金额防篡改、正式文书等语境时保留大写并核对书写正确。
5. **同份字幕内统一**：同一类别数字在同一份字幕中写法一致——出现"2024年"就不应再出现"二零二四年"；出现"50%"就不应再出现"百分之五十"。
6. **只改写法，不改数值**：数字所代表的量值不变，仅调整书写形式；不确定语境时标注"⚠️ 请确认"。

### 6.2 使用阿拉伯数字（默认优先）

| 类别 | 示例（修改后） |
|------|---------------|
| 年份/日期/时间 | 2024年、8月13日、16点30分（"二零二四年"→"2024年"） |
| 度量/小数/百分比 | 3.14、50%、-5℃、100千米、5毫克（"百分之五十"→"50%"） |
| 编号/版本/统计 | 第3组、版本2.0、1200人、排名第8 |
| 年龄 | 45岁（"四十五岁"→"45岁"） |
| 金额/数量（统计报告语境） | 12000元、1200人（"花了一万二"在口语叙述中保留汉字，见 6.3；表格/数据陈述"经费12000元"用阿拉伯） |

> 大数字（≥1万）可保留"万"作单位：1.2万、3万（单位前用阿拉伯数字）。

> **口语叙述 vs 精确统计的分界（人工校对高频项，重点）**：说话人**口述叙述**（讲故事、回忆经历）中的时长、金额、次数**保留汉字数字**——"行医十二年""走了八年""花了十万块钱"（改"12年""8年""10万块钱"破坏口语语感）；**客观陈述/数据报告**（介绍参数、统计结果、引用数据）用阿拉伯数字——"治愈率30%""随访40%""1200人"。同一句内两类并存时各自遵循（"三十年来治疗了1200人"）。拿不准时问：这句是在**讲故事**还是**报数据**？讲故事→汉字，报数据→阿拉伯。

> **千分位逗号删除（重点）**：数字进位中的千分位分隔逗号（1,200,000、3,000,000）**一律删除**——数字内部不允许出现任何标点/分隔符（与"标点全部清除"原则一致），改为**连续数字**（1200000）或按口语习惯以**"万/亿"为单位改写**（120万）。**注意区分**：SRT **时间码行**中的逗号（00:00:01,000）是时间码格式的组成部分，**不属于文本内容，保留不改**；本规则仅针对**文本行内数字**中的千分位逗号。

> **小数点校验（人工校对反馈，重点）**：AI 转写在处理带小数的大数字时**容易丢失小数点**，导致数值差 10 倍甚至百倍（"1.5亿"被写成"15亿"）。校对时对**涉及金额/数量/统计的大数字**做小数点核对：①口语中的小数（1.5亿、2.3万、3.14）逐位核对小数点位置，**"1.5亿"写成"15亿""1.2万"写成"12万"均为丢失小数点**；②结合语境判断量级是否合理（纪录片讲产值/规模时，"1.5亿"与"15亿"量级差异巨大，按上下文推断）；③大数字出现"整十倍数"且语境明显不符时（如"15亿"语境应为亿元级规模但说法可疑），回听原音核对；无法确认的标注"⚠️ 请确认"。修改类型标注【数字】。

> **数值听写错误修正（人工校对反馈 2026-08 确认，重点）**：AI 转写除丢失小数点外，还常产生**数值听写错误**——倍率、百分比、分数被听错。《幸福来敲门》人工校对确认案例：18倍→**1.8倍**、17倍→**1.7倍**、38→**3.8**、1%→**三分之一**、3%→**三分之二**、百分之九十→**99%**。**语境明显不合理的数值允许直接修正**，判断依据按优先级：
> 1. **有音频/画面证据**（工作方式一/二）：回听原音或画面文字核对，以真实语音为准修正；
> 2. **量级与常识矛盾**：上下文讲营养/健康提升幅度时"18倍"远超常识、"1.8倍"合理，此类明显矛盾可直接修正；
> 3. **前后文数字互证**：同一事实前后表述不一致时，以多数一致/更合理的表述为准。
> **修正时标注【数字】并在修改说明表中列明"原文 → 修正后 → 依据"**（如"18倍 → 1.8倍 → 语境为营养提升幅度，1.8倍合理"）；**语境无法判断合理性的（两种读法都通）一律标"⚠️ 请确认"不改**。注意：本规则修的是**听写错误**（AI 听错数值），与"只改写法不改数值"（书写形式统一）不冲突。

### 6.3 保留汉字数字（不改写）

| 类别 | 示例 |
|------|------|
| 成语/惯用语 | 独一无二、三心二意、七上八下、十万八千里、一心一意 |
| 概数 | 三四个、五六天、几十个、上百、七八十人 |
| 农历/节气/朝代 | 初一、正月十五、五代十国、二十四节气 |
| 固定口语表达 | 第一、第二、三番五次、十有八九 |
| 俗语/熟语中的数字 | 睡不着减五岁、三天打鱼两天晒网、一波三折 | "减五岁"保留汉字，不改写为"减5岁" |
| **含数字的固定药名/成药名称** | **七十味珍珠丸、二十五味珊瑚丸、六味地黄丸、十全大补丸、三七片** | 药名是固定名称（如中成药/藏药注册名），数字是名称组成部分，**一律保留汉字，不改写为"70味珍珠丸""25味珊瑚丸"** |
| **概数/约数（带约估词）** | **五十多万、二十多年、三百多例、十来年、八九十个** | 数字后带"多/来/余/几/上下/左右"等约估词，或本身是概数，**整体保留汉字**，不改写为"50多万""20多年" |
| **口语叙述中的时间长度/金额** | **十二年、八年、五分钟、十万块钱、五万块钱** | 说话人讲故事/回忆中口述的时长与金额，**保留汉字数字**；客观统计/报告语境仍用阿拉伯（见 6.2 分界）。**人工校对反馈（重点）**：AI 转写把口语时长写成阿拉伯时改回汉字——"10年20年"→"十年二十年"、"30年了"→"三十年了"、"她有10年的糖尿病史"→"她有十年的糖尿病史"；精确的统计/比例仍用阿拉伯（"51:62""2400""200位60岁以上的慢性病老人"） |

> "第一/第二"等口语序数可保留汉字；但编号类（第3组、5号楼）用阿拉伯数字。同一份字幕内同类表达需统一。
> **分歧裁决记录（2026-08-28 用户确认）**：《幸福来敲门》人工校对稿曾把小数额数量改为汉字（2万户→两万户、3罐→三罐、8倍→八倍、5万→五万），与本节"数量默认阿拉伯数字"冲突；经用户裁决**维持数量用阿拉伯数字（1200人）不变**，仅时长/金额/次数的口语叙述保留汉字（见 6.3 分界），后续校对仍按本节执行。
> **含数字的固定药名保留汉字（人工校对高频项，重点）**：中成药、藏药、蒙药等**成药名称**（"七十味珍珠丸""二十五味珊瑚丸"）如同"六味地黄丸"，是**固定专有名称**，名称中的数字是药名组成部分——**一律保留汉字数字，不得改为阿拉伯数字**；此类药名即使多次出现（如"七十味珍珠丸"出现 9 次）也必须全部保持一致、统一汉字。
> **俗语/熟语中的数字保留汉字（人工校对高频项）**：说话人引用俗语、熟语、口头惯用说法时（"睡不着减五岁"），其中的数字是表达的一部分，改阿拉伯数字会破坏语感，**保留汉字数字**；普通叙述性年龄/数量（"他今年45岁"）仍用阿拉伯数字，两者不冲突。
> **字母分类/型号保持规范大小写**：字幕中的字母分类/型号标识（A类、B类、维生素C、X光）按规范写法保留大写；AI 误转为小写时（"a类"→"A类"）修正，不改变其含义。

### 6.4 汉字大写数字（壹贰叁…）的使用

- **使用场合**：金额防篡改（人民币壹万贰仟元整）、合同/票据/正式文书中的金额。
- **字幕中出现时**：**保留大写写法**，并逐字核对是否正确（壹贰叁肆伍陆柒捌玖拾佰仟万亿），错误则修正，**不转换为阿拉伯数字**。
- **注意区分**：普通口语叙述金额（"花了一万二""值两千块钱"）不属于防篡改场合，统一为阿拉伯数字（"12000元""2000元"）。

### 6.5 示例

### 6.6 处理原则

- **书写形式不改数值；听写错误按规则修正**：数字书写统一**只改写法不改量值**；数值听写错误（18倍→1.8倍类，AI 听错数值且语境明显不合理）按 6.2"数值听写错误修正"规则处理并标注【数字】+修改依据；数字相关识别错误（如"1200人"误为"1020人"）按错字规则处理并标注。
- **小数点必保（人工校对反馈高频项，重点）**：数值中的小数点（`.`）是数值的一部分，**不是标点符号，一律保留不得删除**。标点清除时小数点不在清除范围；数字书写统一时也不得将小数去掉。常见场景：
  - 年龄带小数：87.5岁（**不改为**"875岁"或"八十七点五岁"）
  - 面积/度量带小数：2.5平方米（**不改为**"25平方米"）
  - 寿命数据带小数：76.2岁变成了87.5岁（**不改为**"762岁变成了875岁"）
  - 百分比带小数：3.14、0.5%
  - **批量处理时务必保护小数点**：若用正则/脚本处理数字（如删除千分位逗号），必须先保护小数点不被误删——先匹配并保护 `\d+\.\d+` 模式，再处理其他数字。
- **千分位逗号必删**：文本行数字内的千分位逗号一律删除（改为连续数字或以"万/亿"为单位改写），与"标点全部清除"原则一致；**时间码行中的逗号属格式成分，保留不改**。
- **口述叙述 vs 统计数据分界**：讲故事/回忆中的时长、金额、次数保留汉字数字（十二年、十万块钱）；报数据/引参数用阿拉伯数字（30%、1200人）——**拿不准时问"讲故事还是报数据"**。
- **固定名称不改写**：含数字的固定药名/产品名/专有名称（七十味珍珠丸、六味地黄丸）中的数字一律保留汉字，多处出现时保持一致。
- **概数不改写**：带"多/来/余/几/上下/左右"等约估词的概数（五十多万、二十多年）保留汉字数字，不转为阿拉伯。
- **视频模式**：转写稿中的数字（如"二零二四"）同样按本节统一为阿拉伯数字；以实际语音确认数值后再改写法。
- **作品名中的数字**：作品名保持原名写法（如《1984》），书名号规则照常适用，数字不另行改写。
- **无法判断时标注**：数字写法不确定时标注"⚠️ 请确认"。
- **修改类型标注【数字】**：修改说明表中逐条列出"原文 → 修改后 → 数字"。

## 七、空格隔写规则（【空格】）

标点已全部删除、**校对不换行**后，行内需要分隔的位置一律用**空格**表达——**空格是字幕唯一的断句分隔手段（"隐形标点"）**，承担并列词、停顿、句子边界三类分隔，帮助观众区分词边界、感知说话停顿节奏。

### 7.1 并列词空格隔写（必须）

同一字幕条目（同一条时间码）内出现**并列关系的词**时，每个并列项之间加**半角空格**隔写：

- **名词并列**：苹果 香蕉 橘子 / 温度 湿度 气压
- **动词并列**：跑 跳 投 / 分析 比对 验证
- **形容词并列**：高 矮 胖 瘦 / 清晰 准确 完整
- **数字/量词并列**：一组 两组 三组

> **判断标准**：并列关系的词之间需要隔写；**连接词"和/跟/以及/与/或"一律保留不删**——这些连接词承载并列语义，是句子的结构成分，删除会导致语义粘连或句子结构残缺。
> **有连接词时保留连接词，不加空格**（"苹果和香蕉"→"苹果和香蕉"，保留"和"不加空格）；**无连接词、并列词直接紧挨时才加空格**（`苹果香蕉橘子` → `苹果 香蕉 橘子`，并列项之间加空格、不加顿号等标点）。
> **关键区分**：删除口语填充词（嗯/啊/这个/那个）后残留的并列词需要加空格（"苹果和香蕉"中"和"是连接词保留）；但如果"和"前后的词本来就直接紧挨无连接词，才加空格隔写。
> **必做要求**：同一条目内凡符合并列判断标准的词**一律空格隔写，不得遗漏**——但**连接词"和/跟/以及/与/或"不属于空格隔写对象，一律保留原样**。包括：直接紧挨的并列项（`苹果 香蕉 橘子`）、列举多个对象（`温度 湿度 气压 风速`）、同类别术语并提（`基因 蛋白质 细胞`）、数字/量词并列（`一组 两组 三组`）、多音节并列词（`分析 比对 验证`）。逐词检查，逐项隔写，宁多勿漏。

> **四字功效/成语并列（人工校对高频项，重点）**：中医**四字功效短语并列**（都是"动词+名词"的固定表述）是最易漏加空格的高频场景——`解毒排毒止血消肿`→`解毒排毒 止血消肿`、`软坚散结活血化瘀`→`软坚散结 活血化瘀`、`活血化瘀通络止痛`→`活血化瘀 通络止痛`、`祛风除湿散寒止痛`→`祛风除湿 散寒止痛`。判断标准：**两个及以上四字功效短语连续出现且中间无连接词时，短语之间加空格**（短语内部不加）。
> **并列药名/成分（重点）**：同一条目内列举多个药名/成分时药名之间加空格——`大蓟大黄等中药`→`大蓟 大黄等中药`、`黄芪当归党参`→`黄芪 当归 党参`、`虫草灵芝孢子粉`→`虫草 灵芝孢子粉`（药名+复数总称"等X"作为整体保留，不加空格）。
> **并列职务/头衔（重点）**：同一人名后的多个职务/头衔之间加空格——`清华大学教授博士生导师`→`清华大学教授 博士生导师`、`主任医师硕士生导师`→`主任医师 硕士生导师`（职务之间不加顿号、用空格）。
> **错误加空格须去除（反向检查）**：非并列、非停顿处**不得**加空格——`你不能说老是被 人说`→`你不能说老是被人说`（"被人说"是完整被动结构，中间不得隔开）。加空格前自问：这里是**并列词**还是**停顿**？都不是→不加。

### 7.2 停顿空格隔写（说话有停顿处）

说话有停顿的地方（换气、句中停顿、句末长停顿、列举停顿、思考停顿）用空格隔写：

- **视频模式**：以转写稿时间戳间隙为依据——相邻词段时间间隔明显（约 > 0.3 秒）即为停顿处，加空格。
- **纯文本/无语音依据**：按语义与说话节奏判断——列举、强调、转折前等自然停顿的位置加空格。
- **称呼/称谓后的停顿（人工校对高频项）**：说话人称呼对方、问候观众或自我介绍后常有停顿——**老师 您好、主持人 您好、各位观众 大家好、朋友们 大家好**——称呼/问候语与后面内容之间加空格。
- **应答词后的停顿（人工校对高频项）**：回答开头先用应答/承接词（对、没错、是的、好、可以、没问题、就是说、也就是说）再进入正题时，应答词与正文之间加空格——**对 也就是说、没错 如果、是的 这个问题**。
- **停顿分级（不换行）**：**长停顿（句末/大换气/句子边界）→ 空格**；**短停顿（句中）→ 空格**。所有停顿一律用空格表达，不做换行处理。

### 7.3 空格使用规范

| 项目 | 规则 |
|------|------|
| 空格字符 | **半角空格（U+0020）**，一个并列项/停顿之间一个空格 |
| 空格后 | 不得跟任何标点（标点已全部删除） |
| 专业术语内部 | 不加（光合作用、人工智能、黑洞） |
| 人名/地名/机构名 | 不加（爱因斯坦、珠穆朗玛峰） |
| 固定搭配内部 | 不加（因为……所以、不是……而是、越来越、一方面……另一方面） |
| **连接词** | **"和/跟/以及/与/或"等连接词一律保留不删**——有连接词处不加空格（"苹果和香蕉"保持原样），仅无连接词的并列词直接紧挨时才加空格 |
| 数字与单位之间 | 不加（3.14、50%、-5℃、km/h 为数值整体，不加空格） |
| 时间码行 | 不涉及（空格只作用于文本行） |

### 7.4 空格是唯一的分隔手段（不换行）

| 分隔对象 | 手段 |
|---------|------|
| 并列词之间 | **空格** |
| 句中短停顿 | **空格** |
| 句末长停顿 / 句子边界 | **空格** |

> - **校对不换行**：字幕条目文本保持单行，不做任何断句换行处理，由剪映播放器按画面自动折行。
> - 空格承担全部三类分隔：并列词、短停顿、句子边界——句子之间用空格分隔，不再用换行断句。
> - 同一条目内：先按并列词与停顿加空格，句子边界处同样以空格分隔。

### 7.5 示例

```
修改前：
3
00:00:08,000 --> 00:00:11,500
然后呢，这个实验他其实，就是说，温度升高之后反应速率会明显加快，还会影响气压、湿度和温度这些指标

修改后：
3
00:00:08,000 --> 00:00:11,500
这个实验它其实温度升高之后反应速率会明显加快 还会影响气压 湿度和温度这些指标
```

> 序号、时间码、空行完全不变；口语词与标点全部删除；顿号删除后"气压"与"湿度"之间加空格；**连接词"和"保留**（"湿度和温度"保持原样不加空格）；"会明显加快 还会影响"处为语音停顿加空格；**条目文本保持单行，未做任何换行处理**。

```
修改前：老师您好我想请教一个问题，对，也就是说这个方案是可行的
修改后：老师 您好 我想请教一个问题 对 也就是说这个方案是可行的
```
> "老师 您好"为称呼/称谓后停顿加空格；"对 也就是说"为应答词后停顿加空格。

## 八、SRT 时间码保留规则（【格式】）

### 8.1 SRT 格式识别

剪映导出的字幕文件（.srt）结构如下，**每 4 行为一个条目**：

```
1
00:00:01,000 --> 00:00:04,000
这个实验的核心原理
是温度升高反应更快

2
00:00:04,500 --> 00:00:07,000
科学家认为数据可能
受到采集方法的影响
```

- **序号行**：从 1 开始递增的数字
- **时间码行**：`HH:MM:SS,mmm --> HH:MM:SS,mmm`（毫秒用英文逗号）
- **文本行**：条目文本保持单行，**校对不换行**——不新增、不删除条目内的换行；**条目之间允许合并过碎的拆句、重新拆分不当长句（见 10.4 / 11.2）**
- **空行**：条目之间的分隔

### 8.2 保留规则（最高优先级）

| 元素 | 处理方式 |
|------|---------|
| 序号 | 原样保留，不重排 |
| 时间码 | 原样保留，一字不改 |
| 空行 | 原样保留 |
| 条目数量 | **默认原样保留**；仅合并过碎拆句/重拆不当长句时随之增减（见 10.4） |
| 文本内容 | **可修改**（错字、口语词、标点、空格、代词、语序）；**可重新断句拆条**——合并过碎拆句、重拆不当长句，每条≤17字；条目文本保持单行（不换行） |

### 8.3 修改示例

```
修改前：
3
00:00:08,000 --> 00:00:11,500
然后呢，这个实验他其实，就是说，温度升高之后反应速率会明显加快

修改后：
3
00:00:08,000 --> 00:00:11,500
这个实验它其实温度升高之后反应速率会明显加快
```

> 序号、时间码、空行完全不变；删除"然后呢""就是说"；"他"改为"它"；**逗号全部清除**；**条目文本保持单行，未换行**；若条目内存在并列词或停顿处，另按第七章规则加空格隔写。

### 8.4 剪映重新导入要求

- 校对后的 SRT 文件需保持**UTF-8 编码、.srt 后缀**，剪映「文本 → 字幕 → 导入字幕」即可直接使用。
- 时间码毫秒分隔符必须是英文逗号（`,`），不要用中文逗号或句点。

## 九、工作方式二：视频语音比对校对规则（视频 + 字幕，【语音比对】）

### 9.1 适用场景与两阶段流程

此为**工作方式二**：用户提供**视频文件**（mp4/mov/mkv 等）与**对应的字幕SRT**，要求按实际语音校对字幕时启用。**本方式按两阶段流程校对**：

| 阶段 | 内容 | 依据 |
|------|------|------|
| **第一阶段：语音比对初步校对** | 提取视频语音转写，与字幕逐条比对，**修正文字准确度问题**——错字、语音识别错误、**空格隔写**（并列词与停顿处以实际语音为准）；同时记录语音中出现的**作品名**（供第二阶段添加书名号） | 视频真实语音（转写稿） |
| **第二阶段：规则二次校对** | 在初步校对结果上，独立按本规则库逐项精校——口语词一律删除（含"这个/那个"）、标点清除（书名号除外）、**书名号添加**、**代词（她/他/它）准确使用修改**、语序修正、**数字书写统一**、空格隔写复核（**不换行，条目文本保持单行**） | 校对规则库（第一至八章） |

输入形式：

| 输入 | 处理方式 |
|------|---------|
| 视频 + SRT 字幕 | **先第一阶段**（语音比对初步校对），**再第二阶段**（规则二次校对），输出校对后 SRT（**生成在原字幕同文件夹下**；中间产物存AI默认存储路径）+ 比对报告 |
| 视频 + 纯文本字幕 | 第一阶段转写后按时间对齐比对文字；第二阶段的文字校对照常；输出全文文本 |
| 仅视频（无字幕） | **直接生成字幕SRT**（见第十章）：转写 → 根据视频语音停顿与意群合理断句（**完整一句话=一条字幕（不凑字）**，**一行最多≤17字（17是上限不是目标）**，只有一句话超17字才拆条；**"XX的XX"偏正短语不拆条**）→ 生成带时间码的 SRT → 按规则二次校对（允许重新断句拆条：合并过碎拆句、重拆不当长句，单条≤17字）→ 中间产物存AI生成产物的默认存储路径、**在原视频文件夹下生成校对完成的 SRT** |
| 仅字幕 SRT（无视频） | **直接进入二次校对**（见第十一章，工作方式三）：跳过音频比对，直接按规则库精校（允许重新断句拆条：合并过碎拆句、重拆不当长句，单条≤17字；未涉及条目序号/时间码保持原样）→ **在原字幕SRT文件夹下生成校对完成的 SRT**，无比对报告 |

### 9.2 工具路径（第一阶段，本地执行）

1. **检查工具**：确认 ffmpeg 与 faster-whisper 可用（`ffmpeg -version`；Python 能 `import faster_whisper`）。本机参考环境：`C:/Users/Administrator/.workbuddy/binaries/python/envs/subtitle` 已装 faster-whisper。缺失时**明确告知无法转写**，降级为纯文本校对（直接进入第二阶段），并提示安装（pip install faster-whisper；ffmpeg 加入 PATH；模型下载设 `HF_ENDPOINT=https://hf-mirror.com`）。
2. **提取音频**：`ffmpeg -i 视频.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 audio.wav`（16kHz 单声道 wav 转写最稳）。
3. **语音转写**：faster-whisper 加载模型（`small` 平衡速度与准确度，`medium`/`large-v3` 更准但更慢），语言指定 `zh`，开启时间戳输出，得到**带时间码的转写稿**。
4. **繁转简（必做）**：Whisper 转写常默认输出繁体（训练数据繁体占比高，`language="zh"` 不区分繁简），**转写稿无论繁简一律执行一次 OpenCC `t2s` 字符转换**（见 1.6），确保转写稿为简体——**发现繁体绝不重新转写**，直接字符级转换。
5. **转写清洗**：转写稿同样按口语词一律删除、标点清除（书名号除外）规则处理，得到"语音标准文本"。
6. **逐条比对**：将 SRT 每条目文本与其时间码区间 [t_start, t_end] 内的转写语音对齐比对（见 9.3）。
7. **初步修正**：按比对结果**直接修正文字准确度问题**（错字、识别错误、空格隔写），**并直接处理结构缺漏——漏句按语音补加条目、多句删除条目（见 9.3），补加/删除后条目序号连续重排**，输出初步校对稿供第二阶段精校。

> 更细的工具用法可参考本机 `video-subtitle-tool` 技能（scripts/transcribe.py 封装了提取+转写一体流程）。

### 9.3 比对维度

| 维度 | 检查内容 | 处理方式 |
|------|---------|---------|
| 文字准确度 | 字幕文本 vs 该时间段语音实际内容 | **第一阶段直接修正**：按错字/识别错误/空格隔写规则以实际语音为准改正 |
| 时间码对齐 | 字幕条目起止时间 vs 语音片段起止 | 偏差 > 0.5 秒 → 标注"⚠️ 时间偏移 [条目n]"，建议用户核对，**不擅自改时间码** |
| 漏句 | 语音中有、字幕没有的内容（遗漏的话） | **第一阶段直接补加条目（2026-09-02 规则升级，不再只标注）**：为遗漏语音按第十章断句规则生成字幕条目——**完整一句话=一条字幕（不凑字）**、每条一行 ≤17 字、"XX的XX"偏正短语不拆、多人对话按说话人切换拆条（10.2 第10条），时间码取该句语音起止（10.3），**插入正确时间位置、后续条目序号顺延重排**；补加文本随后走第二阶段共用二次校对（口语词删除等）；修改说明表标注【语音比对】"按语音补加条目"。**排除项（不算漏句、不补加）**：纯语气词/哼唱/音乐/环境音、转写清洗已删除的口语词（嗯/啊/这个/那个）、无实义应答声 |
| 多句 | 字幕有、语音没有的内容 | **第一阶段直接删除条目（2026-09-02 规则升级，不再只标注）**：确认该条目时间段语音中无对应内容（转写清洗后仍无）即**删除该条目，后续条目序号顺延重排**；修改说明表标注【语音比对】"语音无对应删除条目"。**不确定时保守处理**：音量低/噪音大/口音重导致疑似漏听而非多余时**不删**，标注"⚠️ 请确认"留给用户决定 |

### 9.4 比对判断要点

1. **以时间码区间定位语音**：取条目 [t_start, t_end]，在该区间内找转写段；若该区间内无语音却有文本 → 时间偏移或字幕多余（多余按 9.3 直接删除，删除前先确认不是音量低/噪音导致的漏听）；有语音但文本对不上 → 文字错误（第一阶段直接修正）；**语音有内容但无字幕条目覆盖 → 漏句（按 9.3 直接补加条目）**。
2. **转写文本先行清洗**：转写稿里同样有"嗯/啊/这个/那个"等口语词，比对前先按规则删除，避免误判为字幕多字。
3. **停顿以时间戳间隙为准**：转写稿相邻词段时间间隔 > 0.3 秒视为停顿处，字幕对应文本处应**加空格隔写**（见第七章 7.2）——此为第一阶段修正项。
4. **作品名记录**：语音中明确说出的书名/文章名等作品名，记录并在**第二阶段添加书名号**（见第三章 3.4）。
5. **人名/术语双重确认**：faster-whisper 对人名、专业术语、同音字误判率高，转写与字幕冲突时结合上下文判断；无法确认的标注"⚠️ 请确认"。
6. **问答访谈按音色分段**：主持人问题与受访者回答音色不同，转写可分段标注 [Q]/[A]，便于核对问答结构与"她/他/它"指代方向。
7. **环境噪音/口音（第一阶段即分辨）**：转写准确度受噪音与口音影响，冲突处谨慎判断，不确定就标注请用户听原片确认；**第一阶段比对时即辨别说话人的方言归属（哪一地区方言）**——识别音变特征（平翘舌/nl/hf/前后鼻音等）与方言词并记录（见 1.5.4），**同步给第二阶段二次校对**（按 1.5 节执行：按音位批量排查系统性错字、方言词保留、口音类修改标注【口音】）。
8. **繁体字幕先转简体（第一阶段）**：用户提供的 SRT 若为繁体（港澳台来源/旧字幕），**比对前先把文本行统一转为简体**（OpenCC `t2s`，只转文本行、时间码与结构不动），再与转写稿比对——转写稿已强制简体，双方基准一致（见 1.6）。
9. **音频无法确定时查看画面文字（第一阶段）**：口音导致同音/近音歧义、专有名词（人名/术语/药名/机构名）不确定、音频模糊或转写与上下文冲突时，**定位到该时间点查看视频画面有无相关文字显示**（PPT/课件、图表标注、节目字幕条、片头片尾文字、实物包装文字等）——**画面明确显示正确写法即以画面文字为准**（标注【画面核对】，说明列注明"经画面文字核对"）；画面无文字或与语境冲突时标注"⚠️ 请确认"，不强行采用（见第一章 1.5.3 步骤5）。

### 9.5 输出结构（视频模式）

```
【修改后字幕文件】（生成在原字幕 SRT 相同文件夹下，命名如 原文件名_校对完成.srt；中间产物保存在AI生成产物的默认存储路径下；
SRT 可直接保存导入剪映；未涉及补加/删除/合并/拆分的条目时间码/序号/空行保持原样；
漏句补加、多句删除后条目序号连续重排）

【语音比对报告】（单独列出，不混入字幕文件）
一、转写摘要：视频语音内容要点
二、文字差异表：| 条目 | 时间段 | 字幕原文 | 语音实际内容 | 处理（第一阶段直接修正项） |
三、时间偏移提醒：| 条目 | 字幕时间 | 语音时间 | 偏差 |
四、漏句/多句处理记录：| 时间段/条目 | 说明 | 处理（已补加/已删除/⚠️ 请确认） |

【修改说明表】
| 序号 | 原文 | 修改后 | 修改类型 | 说明 |
```

> **两阶段分工说明**：第一阶段解决"字幕 vs 语音"的准确度问题（错字、隔写），第二阶段解决"字幕 vs 规范"的成文问题（口语词、标点、书名号、代词、语序、数字、空格复核）。修改说明表中，第一阶段修正项标注【语音比对】，第二阶段修正项标注对应规则类型。

## 十、工作方式一：视频转字幕生成规则（仅视频，【生成】）

> 适用场景（**工作方式一**）：用户**仅提供视频文件**（无字幕）时，由专家直接生成可导入剪映的字幕 SRT。生成后**仍须按本规则库做二次校对**，最终交付校对完成的 SRT。**生成阶段按语音语序断句拆条；二次校对允许重新断句拆条——合并过碎的拆句为一条、长句断句有问题可重新拆分合并（单条≤17字，见 10.4）。**

### 10.1 生成流程（仅视频输入）

| 步骤 | 内容 | 要点 |
|------|------|------|
| 1. 提取音频 | ffmpeg 提取 16kHz 单声道 wav | 与第九章 9.2 相同 |
| 2. 语音转写（**含繁转简**） | faster-whisper（语言 zh）转写为**带逐词时间戳**的文本；**转写后一律执行 OpenCC `t2s` 繁→简字符转换**（Whisper 常默认输出繁体，`language="zh"` 不区分繁简，见 1.6） | 保留每个词的时间戳，供断句与时间码生成；转写稿强制简体，**发现繁体绝不重新转写、直接字符级转换** |
| 3. 断句拆条 | 根据**视频语音**（停顿 + 意群 + **说话人切换**）**合理断句**，生成字幕条目 | **表述的完整一句话就是一条字幕（不凑字、不强拆）**，**一条字幕只有一行、一行最多不超过 17 个字符（17字是上限不是目标）**；只有一句话超过 17 字时才拆成多条字幕（**"XX的XX"偏正短语不拆条**，见 10.2）；**多人对话（问答访谈/聊天/接话）时不同说话人的话强制拆成独立条目——即使接话紧密（间隙<0.3s）、即使字数很少（"嗯""好"也是一条），绝不合并在一条字幕里（见 10.2 第10条）**；**转写中不确定的用词（口音歧义/术语/人名/药名等）先定位画面查看有无相关文字显示核对（见 1.5.3 步骤5）** |
| 4. 生成 SRT | 按断句结果生成序号、时间码、文本行 | 时间码取该句群的语音起止时间（见 10.3） |
| 5. 二次校对 | 按本规则库第二至八章逐项精校 | **允许重新断句拆条**：合并过碎拆句、重拆不当长句，单条≤17字（见 10.4） |
| 6. 输出文件 | 中间产物存AI默认存储路径、校对稿在原视频文件夹下生成 SRT | 生成稿（AI默认存储路径）+ 校对稿（原视频文件夹）（见 10.5） |

### 10.2 断句拆条规则（按语音语序合理断句——完整一句话=一条字幕（不凑字）；一行最多 ≤17 字（17是上限不是目标）；只有一句话超17字才拆条；"XX的XX"偏正短语不拆条）

1. **按视频语音的语序内容合理断句（首要原则）**：**表述的完整一句话就是一条字幕**——不凑字、不强拆，一句话不管几个字（3字、8字、15字都行）都是一条字幕；**17字是上限，不是目标**——不凑满17字、不因行短强行合并。每条字幕（每个 SRT 条目）**只有一行文本**，行内**不允许出现换行**；这一行**最多不超过 17 个字符**（汉字、数字、字母、空格均计 1 个字符），生成阶段与校对阶段（微调断点后）都必须遵守。
2. **只有一句话超过 17 字时才拆条**：一句话超过 17 字时，将这句话**按语音语序表达意思合理断句**拆成**多条字幕**——每条字幕一行、各自独立的时间码，每条≤17字；**不得把多行文本塞进同一条字幕**（一条字幕 = 一行 = 一个 SRT 条目）。一句话不超过17字时不拆、保持完整为一条字幕。
3. **断句优先取语音停顿（断条依据）**：断点**首先取视频语音的实际停顿处**——以转写时间戳间隙为依据，相邻词段时间间隔明显（约 > 0.3 秒）即为语音停顿，**停顿处优先断条**；同一句话内的小停顿（< 0.3 秒）不断条，用空格隔写。**断句以语音节奏为准，不按字数机械硬切**。
4. **停顿落在语义中途时调整到意群边界**：停顿处同时满足**语义完整**（主谓宾齐全、意群完整）时断条效果最佳；若语音停顿落在语义中途（如修饰语与中心词之间、**"XX的XX"偏正短语内部**），优先调整到最近的自然意群边界断条——**"XX的XX"偏正短语整体放在同一条字幕中，断点取在短语之外**，保证每条字幕可独立阅读。
5. **字数上限是兜底，不是首选依据**：按语音停顿与意群断句后，若某条仍超过 17 字，在该条内按意群边界**二次切分**成新的字幕条目，确保不超上限；若一句话本身很短（如 3-10 字），**整句就是一条字幕，属正常、尊重语音节奏**，不得为凑满 17 字把无关内容并入。
6. **同一句话不因停顿拆碎（人工校对高频项，重点）**：**语义完整的一句话，即使中间有语音停顿（含 >0.3 秒的停顿），只要整句不超过 17 字，就整句作为一条字幕**，句内停顿用**空格**隔写而非拆条——避免产生 ≤5 字的孤立语块（❌ "这个正是我们需要"+"科学抗衰老的原因"两条 → ✅ "这个正是我们需要科学抗衰老的原因"一条；❌ "它不用吃药"+"扛几天就好了"两条 → ✅ "它不用吃药扛几天就好了"一条）。**只有当整句超过 17 字时才按停顿/意群拆条**。
7. **不在词内部断句**：术语、人名地名、固定搭配、数字与单位（3.14、50%、-5℃、km/h）必须整词同行，不得拆开。
8. **"XX的XX"偏正短语不拆条（重点）**："XX的XX"（**定语 + "的" + 中心语**）是**偏正短语**，如"宇宙的起源""实验的原理""地球的温度""人类的智慧"——定语与中心语构成一个语义整体，**断句时不得把"的"前后拆到两条字幕里**（❌ "宇宙的"一条、"起源"一条）；若语音停顿恰好落在短语内部（如"宇宙的"后有停顿），**断点调整到短语之外**（短语前或短语后），短语整体留在同一条字幕中；短语本身较长时（如"这个实验的核心原理"）同样保持整个短语同行，需要拆条时从短语外部边界拆分。
9. **断条不带标点**：生成的字幕延续"无标点"规范——条与条之间即天然的分句边界，不再添加句号逗号；行内停顿用空格隔写（见第七章）。
10. **说话人切换强制拆条（多人对话场景，重点）**：**同一时间段内两人及以上对话（问答访谈、多人聊天、接话抢话）时，不同说话人的话必须拆成独立字幕条目**——**即使两人接话紧密、声音之间几乎没有空隙（时间戳间隙 <0.3s），即使每段话字数很少（如"嗯""好""对""可以"仅一两字），也绝不允许把不同人的话凑在一条字幕里**。说话人切换的判定依据：①**音色/音调差异**（不同说话人的音色、音高、语速不同，转写时可按音色分段标注 [Q]/[A]）；②**语义对话逻辑**（一问一答、接话、抢话、补充——语义上分属两个人的独立发言，如 A"你觉得呢"B"可以"）；③**时间戳/音量变化**（说话人切换处常伴随音量或音色突变，即使间隙小也可判定）。**说话人切换的拆条优先级高于停顿合并规则**——"同一句话不因停顿拆碎""避免≤5字孤立语块"等合并规则**只适用于同一说话人自己的话**，**不得把不同说话人的话合并**；A 说"可以"、B 接"那就这么定了"，即使连接紧密也要拆成两条独立字幕。

### 10.3 时间码生成规则

- **条目划分**：**一个条目 = 一条字幕 = 一行文本**（≤17 字）；长句按语音停顿/意群拆成**多个条目**，每条字幕单行、各自独立的时间码。
- **时间码格式**：`HH:MM:SS,mmm --> HH:MM:SS,mmm`（毫秒用英文逗号，与剪映格式一致）。
- **起止取值**：条目开始时间 = 该条字幕首词的时间戳；结束时间 = 最后一个词的时间戳 + 其语音时长（转写稿缺失时长时取与下一条的间隙）。
- **相邻条目衔接**：相邻条目之间保留自然间隙（0.1-0.5 秒），避免首尾重叠；每条字幕各自独立的时间码。
- **生成稿与校对稿时间码**：未涉及合并/拆分的条目，时间码、序号保持生成稿原样；**合并过碎拆句或重拆长句时，涉及条目的序号重排、时间码合并/调整为该句语音起止（见 10.4）**。

### 10.4 生成与校对边界（防止规则冲突）

| 阶段 | 换行/分行 | 说明 |
|------|-----------|------|
| **生成阶段**（转写 → SRT） | **允许断句拆条**：根据视频语音停顿与意群断句，**完整一句话=一条字幕（不凑字）**，**一行最多 ≤17 字（17是上限不是目标）**，只有一句话超17字才拆成多条字幕（**"XX的XX"偏正短语不拆条**） | 断句拆条是生成排版的一部分（按本规则） |
| **校对阶段**（二次校对） | **允许重新断句拆条**：**①合并过碎拆句**（同一句完整语义被拆成的多个短条目、尤其≤5字孤立语块，合并后≤17字，时间码合并为该句语音起止——人工校对实践：1166条合并至922条；**仅限同一说话人自己的话，不同说话人的话即使都很短也绝不合并且，见 10.2 第10条**）；**②重拆不当长句**（断点落在语义中途/意群割裂/语序错乱的长句按语音语序重新拆分合并，拆点取语音停顿/意群边界、偏正短语不拆）；**③说话人混条强制拆开**（一条字幕内混入两人对话——AI 把接话紧密的不同人发言凑成一条——按说话人切换点拆成多条独立条目、各自独立时间码，即使各段字数很少也拆，见 10.2 第10条）；每条≤17字 | 在按规则修改文本内容（错字/口语词/标点/书名号/代词/语序/数字/空格）的同时，允许合并过碎拆句、重拆不当长句、**强制拆开说话人混条**；**任何一条字幕只有一行文本、不超过17字（17是上限不是目标）**；未涉及合并/拆分的条目，序号、时间码、空行保持原样 |

> **规则关系**：本规则（生成与校对均可断句拆条）与第七章/第八章"校对不换行"**不冲突**——"不换行"约束的是**条目文本**（每条字幕只有一行文本，校对不新增/删除条目内的换行）；**二次校对允许的断句拆条是条目层面的合并与拆分**（合并过碎拆句、重拆不当长句），合并/拆分后**任何一条字幕仍只有一行、且不超过 17 字（17字是上限不是目标）**，涉及条目的时间码随之调整、未涉及条目保持原样。

> **内容保留是合并/拆分的最高原则（人工校对反馈，重点）**：专家版过度拆分（602条）导致 **63 处内容遗漏**，人工版合并为 522 条后完整保留语义——**合并过碎拆句、重拆不当长句时，合并/拆分后的文本必须逐词核对，确保原句每个词都保留、不得遗漏任何成分**。高频遗漏点：①**句末补足成分**（"凌晨被五步蛇咬伤后"漏"剧痛难忍"、"家人紧急送至"漏"祁门蛇伤研究所"）；②**并列后半段**（"出血性毒"漏"和神经性毒"）；③**引文/称号后半段**（"《本草纲目》"漏"称祁蛇为风痹惊搐"、"祁门被称为"漏"御医之乡"）；④**动作补语**（"观察研究后"漏"再将其放生"）。具体检查法：合并条目时**把原句完整读一遍再合并**，合并后与原句逐字对照；**"XX的XX"偏正短语不拆、并列成分不拆、引文不拆**；宁可在一条内达到17字上限，也不拆丢内容。**合并边界（说话人，重点）**：合并**只允许在同一说话人的连续发言内进行**——A 说"这个呢"、B 接"对"，即使两段都很短、即使接话紧密无空隙，也**不得合并成一条**（见 10.2 第10条）；合并后若仍存在无法确认的碎片，保留完整句意并标注"⚠️ 请确认"。

### 10.5 输出规范（生成模式）

- **输出位置**：生成稿等中间产物保存在**AI生成产物的默认存储路径**下，校对稿在原视频文件相同文件夹下生成。
- **生成稿**：`原视频名_字幕.srt`——转写断句生成的原始字幕（含口语词与转写错误，中间产物，保存在**AI生成产物的默认存储路径**下）。
- **校对稿（最终交付）**：`原视频名_校对完成.srt`——二次校对完成、可直接导入剪映的字幕。
- **告知用户**：明确告知校对稿保存路径（原视频文件夹），并说明**供剪映导入的是校对稿**（`原视频名_校对完成.srt`）；生成稿保存在AI默认存储路径、便于核对修改痕迹。
- **配套输出**：修改说明表（生成稿 → 校对稿的差异，修改类型标注【生成】及对应规则类型）；转写中无法确认的人名/术语标注"⚠️ 请确认"。
- 工具缺失（ffmpeg / faster-whisper）时无法生成，明确告知用户并给出安装提示（见第九章 9.2）。

## 十一、工作方式三：仅字幕SRT直接二次校对（仅SRT输入）

> 适用场景（**工作方式三**）：用户**仅提供字幕SRT文件**（无视频）时，无需读取视频语音，**直接对提供的字幕按本规则库执行二次校对**，最终在**原字幕SRT文件夹**下生成校对完成的 SRT。

### 11.1 适用与流程

| 步骤 | 内容 | 要点 |
|------|------|------|
| 1. 输入识别 | 确认输入为**仅字幕SRT文件**（带序号、时间码），无视频文件 | 走工作方式三；有视频则走工作方式一/二；纯文本走纯文本模式 |
| 1.5 繁简检查 | **检查文本行是否为繁体**（"這/為/後/們"等），是则先用 OpenCC `t2s` 把文本行统一转为简体 | 默认输出简体；序号、时间码、空行、条目结构不动（见 1.6）；用户明确要求保留繁体时跳过 |
| 2. 二次校对 | 按「二次校对执行顺序」逐项精校（通读查证 → 错字 → 口语词 → 标点 → 书名号 → 代词 → 语序 → 数字 → 空格 → 复核） | 修改文本内容并**允许重新断句拆条**：合并过碎拆句、重拆不当长句、**说话人混条强制拆开**，每条≤17字；**合并仅限同一说话人（见 10.2 第10条）**；未涉及条目序号/时间码/空行保持原样，条目文本保持单行（不换行） |
| 3. 输出文件 | 在原字幕SRT文件夹下生成校对完成的 SRT | `原文件名_校对完成.srt`（见 11.3） |

### 11.2 与工作方式二的区别

| 项目 | 工作方式二（视频+字幕） | 工作方式三（仅字幕SRT） |
|------|------------------------|------------------------|
| 输入 | 视频文件 + 对应字幕SRT | 仅字幕SRT文件 |
| 第一阶段 | 语音比对初步校对（错字/隔写以实际语音为准修正；**漏句直接补加条目、多句直接删除条目**；时间偏移只标注） | **无**（跳过音频比对） |
| 二次校对 | 按规则库精校 | 按规则库精校（同标准） |
| 比对报告 | 附语音比对报告 | **无** |
| 输出位置 | 原字幕SRT文件夹 | 原字幕SRT文件夹 |

> 工作方式三与工作方式二的**二次校对执行的是同一套标准**（固定顺序、每处修改须有规则依据）；区别仅在于**工作方式三没有第一阶段音频比对**——错字、识别错误等文字问题完全依赖语境判断与查证（上下文互证、外部资料），查证后仍不确定的标注"⚠️ 请确认"，不凭印象擅改。**口音/方言分辨同样在二次校对②中执行**：无音频可回听时，靠上下文通顺度发现口音误判（整词还原），识别出音变特征后按音位批量排查系统性错字，方言词保留；无法确认的一律标注"⚠️ 请确认"（见第一章 1.5.3 步骤4）。**说话人切换判断同样在二次校对中执行（见 10.2 第10条）**：无音频/无音色信息时，靠**语义对话逻辑**判断——一条字幕内出现一问一答、接话、抢话等明显分属两人的独立发言（如"你觉得呢""可以"），即按说话人切换拆成独立条目；纯语义无法判断是否换人时（单句无对话特征），保持原样、不臆测拆条。

### 11.3 输出规范（工作方式三）

- **输出位置**：在原字幕SRT文件相同文件夹下生成。
- **校对稿（最终交付）**：`原文件名_校对完成.srt`——二次校对完成、可直接导入剪映的字幕；**允许重新断句拆条**（合并过碎拆句、重拆不当长句，每条≤17字；**合并仅限同一说话人，说话人混条强制拆开，见 10.2 第10条**），未涉及合并/拆分的条目序号、时间码（`HH:MM:SS,mmm`）、空行保持原样，条目文本保持单行（不换行）。
- **配套输出**：修改说明表（原文 → 修改后 → 修改类型 → 说明，单独列出、不混入字幕文件）。
- **无比对报告**：未读取视频语音，不生成语音比对报告；如需音频比对请提供视频文件（走工作方式二）。
