## 口语词清理的误伤防护（2026-09-02 实战教训）

删除语气词时必须保护以下情况，**已核查全文确认为实词/词干**：

| 保留项 | 原因 | 示例 |
|--------|------|------|
| 好 / 是 / 对（单独成条） | 有效应答，非语气词 | 原文「对」出现 72 次，删除会破坏对话 |
| 干嘛 / 干吗 | 「嘛」是词干组成部分 | "人家约我干嘛" |
| 天呐 | 完整感叹词，删「呐」只剩「天」| "天呐感觉是天方夜谭" |
| 哇哇 | 实词，哭声 | "哇哇在那哭" |
| 还有 / 另外（句首） | 表追加，有实义 | "还有一个广州的三甲医院" |
| 这些 / 那些（句首） | 复数指示，删后主语残缺 | "这些大领导""这些年" |
| 疑问句句尾「呢」 | 保留 | "这个事是什么呢""为什么呢" |
| 确认语气「吧 / 是吧 / 对吧」 | 保留 | "活蹦乱跳是吧" |

### 「这个 / 那个」删除规则（人工稿调优，精确率 100%、召回率 56%）

> ⚠️ **2026-09-02 终裁更新**：方案 E 已被本集人工稿推翻——用户裁决改为**句中口语性冗余直接删除**
> （见下方「本集人工稿终裁规则」第 7 条）。以下保留作历史参考与误删防护边界。

四方案对比结论：

| 方案 | 精确率 | 召回率 | 结论 |
|---|---:|---:|---|
| A 句首保留 + 代词保护 | 100% | 52% | 基线 |
| B 句首删除 + 代词保护 | 62% | 62% | ❌ 29 处误删 |
| **E 句首保留 + 移除「所以/那么/他们/我们」保护** | **100%** | **56%** | ✅ 采用 |
| F E + 扩充前置词 | 88% | 57% | ❌ 6 处误删 |

**规则要点**

1. **句首 / 句尾一律保留**——人工稿证明这是实指或话题标记：
   "这个有机的概念"、"这个新西兰人"、"这个水的抗生素检测"、"早就听说了这个"。
2. **前为肯定应答（对/是/好）或保护词（就/也/还/才/更/最/都/又/却/但/而/而且/但是/因为/如果/虽然/它/他/她/它们/她们/咱/咱们）→ 保留**。
3. **后置保护**：后接"就是/方面/后果/问题/数字/时候/情况/意思/道理/说法/做法/办法"→ 保留。
4. **前置为介词或代词 → 删除**：的、和、与、拿、比、用、给、让、叫、有、需要、支持、提供、照、以、把、从、喝、偏爱、去、是、吃、买、卖、做、像、包括、通过、为、向、往、朝、管、帮、带、送、属于、超过、低于、高于、不如、**他们、我们、你们、大家**、再说、说是、还有、自己、国家。
   例："所以他们**这个**环保意识特别强"→"所以他们环保意识特别强"✓
5. **「的 + 这个/那个 → 的」**："就谁显得更年轻的**那个**意思呢"→"就谁显得更年轻的意思呢"✓
6. **❌ 不要加入「在 / 到 / 跟」作前置触发词**——实测产生 7 处误删（"在这个水库里"、"跟这个同龄人"、"可以达到这个数值"），净收益为负。

### 残留说明

成品中保留的「这个/那个」（约 371 处 / 3262 条）经抽样核查绝大多数为**实指或主语**
（"这个事其实"、"这个环境"、"就是在说这个东西"），符合人工标准，不得继续批量删除。
