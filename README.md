<h1 align="center">字幕精校师 · Subtitle Refiner</h1>

<p align="center">
  A professional WorkBuddy <b>Agent-type expert</b> for proofreading AI-generated video subtitles
  (CapCut / JianYing, 剪映). Three clearly separated workflows, one shared rule-based proofreading engine.
  <br>
  一款专业的 WorkBuddy <b>智能体专家</b>，用于校对剪映等 AI 生成的视频字幕。三种工作方式，共用一套规则化二次校对引擎。
</p>

## ✨ Features · 功能特性

- **Remove ALL filler / spoken particles** — deletes 嗯/啊/哦/哎呦/呃/哎呀 etc. (including answer-initial 嗯/啊/哦 and trailing 呢 particles), plus empty fillers like 这个/那个.
  删除全部口语词与语气词（含应答词、呢字尾），以及"这个/那个"等无实指填充词。
- **Strip punctuation except book-title marks 《》** — only 汉字 / 数字 / 字母 / 《》 / spaces remain; auto-adds 《》 around books, articles, films, programs.
  清除除书名号外的所有标点，并为著作/文章/影视/节目名自动加《》。
- **Space-separated, never line-broken** — coordinate words and speech pauses are joined with a half-width space; spacing is the *only* separator in proofreading.
  并列词与语音停顿以半角空格隔写，校对过程不换行——空格是唯一分隔手段。
- **Accurate pronouns (她/他/它)** — three-step referent tracing; dialect/accent error correction; honorific 你→您 for host-to-guest.
  指代追踪三步法修正代词；方言口音整词还原；主持人对嘉宾敬语化。
- **Unified number formatting** — Arabic numerals for precise values, Chinese numerals for idioms/approximations, 壹贰叁 reserved for anti-tamper amounts; thousands separators removed.
  数字书写统一（阿拉伯数字用于精确值，汉字数字保留于成语/概数，大写数字仅用于金额防篡改）。
- **SRT timestamp & structure preserved** — output re-imports directly into CapCut.
  保留时间码与 SRT 结构，输出可直接重新导入剪映。
- **Series proper-noun glossaries** — per-series term tables (dynamic) so confirmed spellings accumulate across rounds.
  系列专有名词词表机制（glossaries/），越校越准。

## 🔄 Three Workflows · 三种工作方式

| Workflow | Input | Pipeline |
|----------|-------|----------|
| **① Video-only** · 视频直出字幕 | Video file only | Transcribe speech → segment into SRT (one full sentence = one entry, ≤17 chars/line as a ceiling) → shared rule-based second-pass → output SRT in the video folder |
| **② Video + SRT** · 视频+字幕比对 | Video + matching SRT | Audio-vs-subtitle comparison first-pass (fix typos, add missing lines, delete extra lines, re-sequence) → shared rule-based second-pass → output SRT in the subtitle folder |
| **③ SRT-only** · 仅字幕SRT精校 | SRT file only | Skip audio comparison → run the shared rule-based second-pass directly → output SRT in the original folder |

All three share **one ordered rule-based second-pass** proofreading engine, guaranteeing consistent, uniform results.
三种工作方式共用**同一套固定顺序的规则化二次校对**，确保结果准确统一。

## 📦 Installation · 安装

**Option A — Copy into WorkBuddy plugins directory (local)**

```bash
# 1. Clone this repository
git clone https://github.com/<your-username>/subtitle-proofreader.git

# 2. Copy the plugin folder into your WorkBuddy marketplace plugins directory
#    (any marketplace subfolder works, e.g. my-experts/plugins)
cp -r subtitle-proofreader \
  "$HOME/.workbuddy/plugins/marketplaces/my-experts/plugins/subtitle-proofreader"

# 3. Restart WorkBuddy — the expert appears in your Expert list.
```

**Option B — WorkBuddy Open Platform (recommended for sharing)**

Import the bundled `subtitle-proofreader.zip` (generated by `expert-manager`'s `package_expert.py`)
directly via the WorkBuddy Open Platform upload flow. The avatar, manifest, and quick-prompt
cards are all included.

## 🚀 Usage · 使用示例

Just open the **字幕精校师 / Subtitle Refiner** expert and paste one of these:

> 这是我的 SRT 字幕文件（没有视频），请按工作方式三处理：跳过音频比对，直接对字幕执行二次校对——删除所有口语词和标点、为著作文章加书名号、修正错字、统一数字、空格隔写，保留所有时间码和原SRT结构，在原字幕SRT文件夹下生成校对完成的 SRT 供剪映导入。

> 这是视频文件，请按工作方式一处理：直接根据语音生成字幕SRT，一条字幕一行最多 17 字（上限非目标），再按校对规则二次校对，在原视频文件夹下生成校对完成的 SRT。

> 这是视频文件和它的字幕SRT，请按工作方式二处理：先读视频语音与字幕逐条比对、漏句补加/多句删除并连续重排，再二次校对，在原字幕SRT文件夹下生成校对完成的SRT，并附比对报告。
